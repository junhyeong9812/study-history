## 0.5 이 챕터에서 만나는 기호와 읽는 법

```
┌──────────────┬─────────────────────────┬──────────────────────────────────────┐
│ 기호          │ 읽는 법                  │ 의미                                  │
├──────────────┼─────────────────────────┼──────────────────────────────────────┤
│ H(X)         │ "에이치 엑스" 또는        │ X의 (섀넌) 엔트로피                    │
│              │ "엑스의 엔트로피"         │ 불확실성/정보량의 척도                  │
│ H(X,Y)       │ "에이치 엑스 와이"       │ 결합 엔트로피 (joint entropy)           │
│ H(X|Y)       │ "에이치 엑스 기븐 와이"  │ 조건부 엔트로피                        │
│ I(X;Y)       │ "아이 엑스 와이" 또는     │ 상호정보량 (mutual information)        │
│              │ "엑스와 와이의            │ X와 Y가 공유하는 정보량                │
│              │  상호정보량"              │                                      │
│ D_KL(P‖Q)   │ "디 케이엘 피 큐" 또는    │ KL-발산 (Kullback-Leibler divergence)  │
│              │ "케이엘 다이버전스"       │ P와 Q의 차이 (비대칭)                  │
│ H(P,Q)       │ "크로스 엔트로피 피 큐"   │ 교차 엔트로피                         │
│ C            │ "씨" 또는 "채널 용량"     │ 채널 용량 (channel capacity)           │
│ log          │ "로그"                   │ 정보이론에서는 보통 log₂ (단위: 비트)    │
│              │                         │ ML에서는 보통 ln (자연로그)              │
│ bits         │ "비트"                   │ 정보의 단위 (log₂ 사용 시)              │
│ nats         │ "냇"                    │ 정보의 단위 (ln 사용 시)                │
│ p(x)         │ "피 엑스"               │ 확률분포                              │
│ Σ            │ "시그마" (합)            │ 이산 확률변수에 대한 합                 │
│ ∫            │ "적분"                  │ 연속 확률변수에 대한 적분               │
│ R            │ "알"                    │ 전송률 (rate)                         │
│ D            │ "디"                    │ 왜곡 (distortion)                     │
└──────────────┴─────────────────────────┴──────────────────────────────────────┘
```

### 읽기 예시

```
H(X) = -Σ p(x) log p(x)
→ "엑스의 엔트로피는 마이너스 시그마 피엑스 로그 피엑스이다"

I(X;Y) = H(X) - H(X|Y)
→ "엑스와 와이의 상호정보량은 엑스의 엔트로피에서 와이가 주어졌을 때의 
   엑스의 조건부 엔트로피를 뺀 것이다"

D_KL(P‖Q) = Σ P(x) log(P(x)/Q(x))
→ "케이엘 다이버전스 피 큐는 시그마 피엑스 로그 피엑스 오버 큐엑스이다"
→ ‖는 "더블 바"라고 읽거나 그냥 "에서"라고 읽음
```

## 1. 출발점: "정보"란 무엇인가

### 1.1 정보를 수학적으로 정의할 수 있는가

```
일상에서 "정보"는 모호한 개념이다.
섀넌(Shannon, 1948)은 이것에 정확한 수학적 정의를 부여했다.

핵심 통찰:
  정보 = 불확실성의 해소

  "내일 태양이 뜬다" → 거의 확실 → 정보량 ≈ 0 (놀랍지 않다)
  "복권에 당첨되었다" → 매우 불확실했던 것 → 정보량 매우 큼 (놀랍다!)
  
  → 사건이 놀라울수록(확률이 낮을수록) 정보량이 크다.
  → 정보량은 확률의 함수이다.
```

### 1.2 정보량의 정의 — 왜 log인가

```
🔴 [정의] 사건 x의 정보량 (self-information):
  I(x) = -log₂(p(x)) = log₂(1/p(x))

  단위: 비트(bit) (log₂ 사용 시)
```

**왜 하필 log인가 — 세 가지 자연스러운 요구에서 유도:**

```
🟢 [유도 가능]

정보량 함수 I(p)가 만족해야 할 조건을 생각하자:

  조건 1: p가 작을수록 I가 크다 (놀라울수록 정보가 많다)
           → I는 p의 감소함수

  조건 2: I(1) = 0 (확실한 사건은 정보가 없다)

  조건 3: 독립 사건의 정보량은 더해진다 (가산성)
           I(p₁ · p₂) = I(p₁) + I(p₂)
           
           왜: 동전 2번 던지기의 정보 = 각 던지기 정보의 합
           (독립이면 정보가 겹치지 않으므로)

조건 3에서: I(p₁ · p₂) = I(p₁) + I(p₂)
  → 곱을 합으로 바꾸는 유일한 연속 함수 = 로그!
  → I(p) = -log(p)  (부호는 조건 1을 위해)

따라서 log는 "공리에서 유일하게 결정되는" 함수이다.
다른 선택지가 없다!

예시:
  공정한 동전 앞면: p = 1/2 → I = -log₂(1/2) = 1 비트
  주사위 1이 나옴: p = 1/6 → I = -log₂(1/6) ≈ 2.585 비트
  확실한 사건:    p = 1   → I = -log₂(1) = 0 비트
```

## 2. 엔트로피 — 불확실성의 평균

### 2.1 섀넌 엔트로피 — 왜 이 형태인가

```
🔴 [정의] 확률변수 X의 엔트로피:
  H(X) = -Σ p(x) · log₂ p(x) = E[I(X)] = E[-log p(X)]

왜 이 형태인가:
  정보량 I(x) = -log p(x)의 "기댓값(평균)"이다.
  
  H(X) = Σ p(x) · I(x) = Σ p(x) · (-log p(x))
  
  "평균적으로 얼마나 놀라운가" = "평균적 불확실성"
  
  이것이 자연스러운 이유:
    기댓값은 확률에서 "대표값"을 구하는 표준 도구 (Ch.03).
    정보량의 기댓값 = 평균 정보량 = 엔트로피.
```

**엔트로피의 성질 — 왜 이것들이 성립하는가:**

```
🟢 [유도 가능]

  (1) H(X) ≥ 0 (항상 비음수)
      왜: p(x) ≤ 1이므로 -log p(x) ≥ 0. 비음수의 가중평균은 비음수.

  (2) H(X) = 0 ⟺ X가 결정적 (하나의 값만 확률 1)
      왜: 불확실성이 없으면 정보량도 0.

  (3) H(X) ≤ log₂(n)  (n: 가능한 값의 수)
      등호 조건: X가 균등분포일 때.
      왜: 균등분포가 "가장 불확실한" 분포. 특정 값을 선호하면 불확실성 감소.

예시:

  공정한 동전: p(앞) = p(뒤) = 1/2
  H = -(1/2)log(1/2) - (1/2)log(1/2) = -(1/2)(-1) - (1/2)(-1) = 1 비트
  → 동전 한 번 = 1비트의 정보 = 1비트의 불확실성

  편향 동전: p(앞) = 0.99, p(뒤) = 0.01
  H = -0.99·log(0.99) - 0.01·log(0.01) ≈ 0.081 비트
  → 거의 확실 → 불확실성 매우 낮음

  주사위: p(k) = 1/6, k = 1,...,6
  H = log₂(6) ≈ 2.585 비트
  → 동전보다 불확실 → 더 많은 비트 필요

🔵 [CS 연결]
  데이터 압축의 이론적 한계:
    H(X) = 메시지 하나당 필요한 최소 평균 비트 수
    어떤 압축 알고리즘도 H(X) 비트 미만으로는 압축할 수 없다!
    → 이것이 섀넌의 소스 코딩 정리의 핵심
```

## 3. 결합 엔트로피와 조건부 엔트로피

### 3.1 결합 엔트로피

```
🔴 [정의] H(X, Y) = -Σₓ Σᵧ p(x,y) · log p(x,y)

  두 변수를 함께 고려한 총 불확실성.

🟢 [유도 가능] 연쇄 법칙:
  H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

  왜: "X와 Y의 총 불확실성 = X의 불확실성 + X를 안 후 Y의 남은 불확실성"
  
  확률에서: p(x,y) = p(x)·p(y|x)
  log를 취하면: log p(x,y) = log p(x) + log p(y|x)
  기댓값을 취하면: H(X,Y) = H(X) + H(Y|X)  □
```

### 3.2 조건부 엔트로피

```
🔴 [정의]
  H(X|Y) = -Σₓ Σᵧ p(x,y) · log p(x|y)
         = Σᵧ p(y) · H(X|Y=y)

  "Y를 알고 난 후 X에 남아있는 불확실성"

🟢 [유도 가능]
  H(X|Y) ≤ H(X)  (등호: X와 Y가 독립일 때)

  왜: Y를 아는 것은 불확실성을 줄일 수만 있지, 늘릴 수는 없다.
  "정보는 도움이 되거나 최소한 해가 되지 않는다."
```

## 4. 상호정보량 — "X가 Y에 대해 알려주는 것"

```
🔴 [정의]
  I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)

  "Y를 알면 X의 불확실성이 얼마나 줄어드는가"

왜 여러 형태가 동치인가:
  벤 다이어그램으로 이해:

  ┌──────────────────────────────┐
  │          H(X,Y)              │
  │  ┌──────┬──────┬──────┐     │
  │  │H(X|Y)│I(X;Y)│H(Y|X)│     │
  │  └──────┴──────┴──────┘     │
  │  ├──── H(X) ───┤             │
  │          ├──── H(Y) ───┤     │
  └──────────────────────────────┘

  H(X) = H(X|Y) + I(X;Y)         → I(X;Y) = H(X) - H(X|Y)
  H(Y) = H(Y|X) + I(X;Y)         → I(X;Y) = H(Y) - H(Y|X)
  H(X,Y) = H(X) + H(Y) - I(X;Y)  → I(X;Y) = H(X) + H(Y) - H(X,Y)

성질:
  I(X;Y) ≥ 0 (항상 비음수)
  I(X;Y) = 0 ⟺ X와 Y가 독립 (서로 정보를 주지 않음)
  I(X;Y) = I(Y;X) (대칭적 — "X가 Y에 대해 아는 것 = Y가 X에 대해 아는 것")

🔵 [CS 연결]
  특성 선택(feature selection): I(특성; 라벨)이 큰 특성이 유용한 특성
  결정 트리: 분할 기준 = 상호정보량 최대화 (= 정보 이득, information gain)
  독립 성분 분석(ICA): 상호정보량 최소화 → 독립 성분 추출
```

## 5. KL-발산 — 두 분포의 "거리"

```
🔴 [정의] KL-발산 (Kullback-Leibler Divergence):
  D_KL(P ‖ Q) = Σ P(x) · log(P(x) / Q(x))

  "참 분포 P 대신 Q를 사용할 때의 추가 비용"
```

**왜 이 형태인가:**

```
🟢 [유도 가능]

  P가 참 분포일 때:
    최적 코드의 평균 길이 = H(P) = -Σ P(x) log P(x)
    Q를 사용한 코드의 평균 길이 = H(P, Q) = -Σ P(x) log Q(x) (크로스 엔트로피)
  
  추가 비용 = H(P, Q) - H(P)
            = -Σ P(x) log Q(x) - (-Σ P(x) log P(x))
            = Σ P(x) log(P(x)/Q(x))
            = D_KL(P ‖ Q)

  KL-발산 = "잘못된 분포를 쓰는 대가"

성질:
  D_KL(P ‖ Q) ≥ 0 (항상 비음수, 깁스 부등식)
  D_KL(P ‖ Q) = 0 ⟺ P = Q
  D_KL(P ‖ Q) ≠ D_KL(Q ‖ P) (비대칭! 거리가 아님!)

왜 비대칭인가:
  "P가 참인데 Q를 쓰는 비용"과 "Q가 참인데 P를 쓰는 비용"은 다르다.
  비유: 우산이 필요한데 안 가져가는 것(비 맞음) vs
       우산이 필요 없는데 가져가는 것(짐만 됨) → 비용이 다르다.

🔵 [CS 연결]
  VAE (Variational Autoencoder): 잠재 변수 분포와 사전 분포의 KL 최소화
  강화 학습 (TRPO, PPO): 정책 업데이트의 KL 제한
  베이즈 추론: 변분 추론에서 사후분포 근사의 품질 측정
```

## 6. 크로스 엔트로피 — 딥러닝의 손실 함수

```
🔴 [정의]
  H(P, Q) = -Σ P(x) · log Q(x)

  "참 분포 P에서 샘플링하되, Q 기반 코드로 인코딩할 때의 평균 비트 수"

🟢 [유도 가능] 크로스 엔트로피 = 엔트로피 + KL-발산:
  H(P, Q) = H(P) + D_KL(P ‖ Q)
  
  H(P)는 P에 의해 고정이므로:
  H(P, Q) 최소화 ⟺ D_KL(P ‖ Q) 최소화 ⟺ Q를 P에 가깝게 만들기

🔵 [CS 연결 — 딥러닝의 핵심 손실 함수]

  분류 문제:
    P = 참 레이블 분포 (원핫: [0, 0, 1, 0, ...])
    Q = 모델의 예측 확률 (소프트맥스 출력: [0.1, 0.05, 0.7, 0.15, ...])
    
    크로스 엔트로피 손실:
    L = -Σ P(x) log Q(x) = -log Q(정답 클래스)
    
    (P가 원핫이면 정답 클래스의 log 확률만 남음)
    
    이것을 최소화 = 모델이 정답에 높은 확률을 부여하게 만듦
                  = Q를 P에 가깝게 만듦
                  = KL-발산 최소화
                  = MLE (Ch.03)와 동일!

  왜 MSE가 아니라 크로스 엔트로피를 쓰는가:
    확률 분포 사이의 "거리"를 재는 데 크로스 엔트로피가 자연스럽다.
    MSE는 확률의 기하학과 맞지 않아 그래디언트가 느리다.
    크로스 엔트로피는 정보이론적으로 "올바른" 손실 함수이다.
```

## 7. 소스 코딩 — 압축의 한계

### 7.1 섀넌의 소스 코딩 정리

```
🔴 [정리] 섀넌의 제1 정리 (Source Coding Theorem, 1948):

  무손실 압축에서:
    어떤 코드든, 메시지 하나당 평균 길이 ≥ H(X) 비트
    H(X)에 가까운 코드가 존재한다.

  → H(X)가 압축의 이론적 한계이다.

왜 H(X) 미만으로 압축할 수 없는가:
  H(X)보다 적은 비트를 사용하면, 서로 다른 메시지가 같은 코드를 받게 된다
  → 복원 불가능 (비둘기집 원리, Ch.04)
  → 무손실이 아니게 됨

🔵 [CS 연결]
  영어 텍스트: 문자당 엔트로피 ≈ 1~1.5 비트 (ASCII 8비트보다 훨씬 작음)
  → 이론적으로 5~8배 압축 가능
  실제 압축 알고리즘(ZIP, gzip)이 이 한계에 접근한다.
```

### 7.2 허프만 코딩 — 최적 접두사 코드

```
🟢 [유도 가능] 핵심 아이디어:
  자주 나오는 기호는 짧은 코드, 드문 기호는 긴 코드를 부여한다.

  왜 이것이 최적인가:
    평균 코드 길이 = Σ p(x) · length(code(x))
    이것을 최소화하려면 p(x)가 큰 것에 짧은 코드를 줘야 한다.
    
    허프만 알고리즘은 이것을 그리디하게 달성한다:
    1. 확률이 가장 낮은 두 기호를 합친다
    2. 합친 것을 새 기호로 취급하고 반복
    3. 트리를 만들면 각 잎까지의 경로가 코드

  예시:
    A: 0.4, B: 0.3, C: 0.2, D: 0.1
    
    D+C = 0.3
    (D+C) + B = 0.6
    A + (D+C+B) = 1.0
    
    코드: A=0, B=10, C=110, D=111
    평균 길이 = 0.4×1 + 0.3×2 + 0.2×3 + 0.1×3 = 1.9 비트
    H(X) ≈ 1.846 비트
    → 최적에 매우 가깝다!

🔵 JPEG, MP3, ZIP 등 대부분의 압축 알고리즘이 내부적으로 엔트로피 코딩 사용
```

## 8. 채널 코딩 — 노이즈를 이길 수 있는가

### 8.1 채널 용량과 섀넌의 제2 정리

```
🔴 [정의] 채널 용량 (Channel Capacity):
  C = max_{p(x)} I(X; Y)

  "입력 분포를 최적으로 선택했을 때, 채널을 통해 전달할 수 있는 최대 정보량"

🔴 [정리] 섀넌의 제2 정리 (Channel Coding Theorem, 1948):

  전송률 R < C이면:
    적절한 코딩을 사용하여 오류 확률을 0에 가깝게 만들 수 있다.
  
  R > C이면:
    어떤 코딩을 사용하든 오류를 피할 수 없다.

왜 이것이 놀라운가:
  직관적으로, 노이즈가 있으면 오류가 불가피할 것 같다.
  그러나 섀넌은 "충분히 긴 코드를 사용하면, C 이하의 속도로
  사실상 오류 없이 통신할 수 있다"는 것을 증명했다.
  
  대가: 코드가 길어져야 한다 = 지연(latency)이 증가한다.
  
  C가 높을수록 → 더 빠르게 오류 없이 통신 가능
  C = 0이면 → 통신 불가능 (노이즈에 완전히 묻힘)

🔵 [CS 연결]
  5G, Wi-Fi, 위성 통신: 채널 용량 공식으로 전송 한계를 설계
  에러 정정 코드: 터보 코드, LDPC 코드가 C에 근접한 성능 달성
```

### 8.2 이진 대칭 채널 (BSC)

```
가장 단순한 채널 모델:

  입력 0 또는 1, 확률 ε으로 비트가 뒤집힘 (에러)

       1-ε
  0 ───────→ 0
    ╲         ╱
     ε       ε
      ╲     ╱
  1 ───────→ 1
       1-ε

  C = 1 - H(ε)  (비트/전송)

  ε = 0 → C = 1 (완벽한 채널, 비트당 1비트)
  ε = 0.5 → C = 0 (완전 랜덤, 어떤 정보도 전달 못 함)
  ε = 1 → C = 1 (모든 비트가 뒤집힘 → 다시 뒤집으면 복원! 사실상 완벽)
```

## 9. 미분 엔트로피 — 연속 확률변수의 정보량

```
🔴 [정의] 연속 확률변수 X의 미분 엔트로피:
  h(X) = -∫ f(x) · log f(x) dx

  주의: 이산 엔트로피와 달리, h(X)는 음수일 수 있다!
  (연속에서는 "정보량"의 직관이 달라짐)

🟢 [유도 가능] 정규분포의 미분 엔트로피:
  X ~ N(μ, σ²) 이면:
  h(X) = (1/2) · log₂(2πeσ²)

  왜 이 형태: 가우시안 적분 + 정규분포 PDF 대입 후 계산하면 나옴.

🔴 [정리] 최대 엔트로피 원리:
  분산이 σ²로 고정되어 있을 때,
  미분 엔트로피를 최대화하는 분포 = 정규분포

  왜: 정규분포는 "평균과 분산만 알 때 가장 불확실한(가정이 적은) 분포"
  → 정규분포가 자연에서 자주 나타나는 이유 중 하나
  → 사전 지식이 적을 때 정규분포를 가정하는 것이 정보이론적으로 타당
```

## 10. CS에서의 핵심 응용

### 10.1 결정 트리의 분할 기준

```
🔵 정보 이득 (Information Gain) = 분할 전 엔트로피 - 분할 후 조건부 엔트로피

  IG(Y, X) = H(Y) - H(Y|X)  = I(X; Y)  (상호정보량!)

  어떤 특성(X)으로 데이터를 나눴을 때 라벨(Y)의 불확실성이 가장 많이 줄어드는
  특성을 선택한다 → 이것이 ID3, C4.5 알고리즘의 핵심

  예시:
    분할 전: 양성 50%, 음성 50% → H = 1 비트
    특성 A로 분할 후: 
      그룹 1 (60%): 양성 90%, 음성 10% → H ≈ 0.47 비트
      그룹 2 (40%): 양성 10%, 음성 90% → H ≈ 0.47 비트
    H(Y|A) = 0.6 × 0.47 + 0.4 × 0.47 = 0.47 비트
    IG = 1 - 0.47 = 0.53 비트 → 좋은 분할!
```

### 10.2 언어 모델의 평가

```
🔵 퍼플렉서티 (Perplexity):
  PPL = 2^{H(P, Q)}  (크로스 엔트로피의 지수)

  "모델이 다음 토큰을 예측할 때 평균적으로 몇 가지 선택지 중에서
   고민하는가"

  PPL이 낮을수록 → 모델이 확신을 가지고 예측 → 좋은 모델
  
  PPL = 1: 완벽한 예측 (불확실성 0)
  PPL = V (어휘 크기): 완전 랜덤 (균등분포만큼 불확실)
```

### 10.3 데이터 압축의 실제

```
🔵 실제 압축 알고리즘과 정보이론의 관계:

  ┌─────────────┬──────────────────────┬────────────────────┐
  │ 알고리즘      │ 정보이론적 원리        │ 사용처              │
  ├─────────────┼──────────────────────┼────────────────────┤
  │ 허프만 코딩   │ 최적 접두사 코드       │ ZIP, JPEG 내부      │
  │ 산술 코딩     │ H(X)에 가장 근접      │ JPEG2000, H.265    │
  │ LZ77/LZ78    │ 패턴 반복 이용        │ gzip, PNG          │
  │ LZW          │ 사전 기반 압축        │ GIF                │
```

## 12. 정리 — 정보이론을 관통하는 원리

```
[원리 1] 정보량 = -log(확률). 놀라울수록 정보가 많다.
  → log가 유일한 선택인 이유: 독립 사건의 정보가 더해지는 조건에서 유도.

[원리 2] 엔트로피 = 평균 정보량 = 불확실성의 척도.
  → 압축의 이론적 하한, 균등분포에서 최대.

[원리 3] 조건부 엔트로피: 정보를 알면 불확실성은 줄어든다 (또는 유지).
  → H(X|Y) ≤ H(X)

[원리 4] 상호정보량 = 공유된 정보 = 특성 선택의 기준.
  → I(X;Y) = H(X) - H(X|Y)

[원리 5] KL-발산 = 분포 차이의 비용. 크로스 엔트로피 = H + KL.
  → 딥러닝 손실 함수의 이론적 근거.

[원리 6] 소스 코딩: H(X) 미만으로 무손실 압축 불가.
[원리 7] 채널 코딩: R < C이면 오류 없는 통신 가능.

외워야 할 것:
  🔴 H(X) = -Σ p(x) log p(x) (엔트로피 정의)
  🔴 I(X;Y) = H(X) - H(X|Y) (상호정보량)
  🔴 D_KL(P‖Q) = Σ P log(P/Q) (KL-발산)
  🔴 H(P,Q) = H(P) + D_KL(P‖Q) (크로스 엔트로피 분해)
  🔴 소스 코딩 정리 (H가 압축 한계)
  🔴 채널 코딩 정리 (C가 통신 한계)

유도할 수 있는 것:
  🟢 I(x) = -log p(x)가 유일한 형태인 이유 (3가지 공리에서)
  🟢 H(X,Y) = H(X) + H(Y|X) (연쇄 법칙, 확률 연쇄에서)
  🟢 KL ≥ 0 (깁스 부등식)
  🟢 크로스 엔트로피 최소화 = MLE
```
