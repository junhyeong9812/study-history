### 읽기 예시

```
P(A|B) = P(B|A)·P(A) / P(B)
→ "비가 주어졌을 때 에이의 확률은,
   에이가 주어졌을 때 비의 확률 곱하기 에이의 확률을
   비의 확률로 나눈 것이다"  — 이것이 베이즈 정리

E[X] = Σ xᵢ · P(X = xᵢ)
→ "엑스의 기댓값은, 각 값 xᵢ에 그 확률을 곱한 것의 합이다"

X ~ N(0, 1)
→ "엑스는 평균 0, 분산 1인 표준정규분포를 따른다"

θ̂_MLE = argmax_θ L(θ)
→ "세타 햇 엠엘이는, 우도함수 L을 최대화하는 세타이다"
→ argmax는 "최대값을 주는 인수(argument of the maximum)"
```

## 1. 출발점: 왜 확률이 필요한가

### 1.1 불확실성의 수학

```
세상은 불확실하다.

  - 동전을 던지면 앞면이 나올까 뒷면이 나올까? → 모른다
  - 내일 비가 올까? → 모른다
  - 이 메일이 스팸일까? → 모른다
  - 이 환자가 암인가? → 모른다

확률은 "모른다"를 수학적으로 다루는 도구이다.
"모른다"를 0과 1 사이의 숫자로 표현하여, 불확실성에 대해 논리적으로 추론한다.

  P = 0:    절대 안 일어남
  P = 0.5:  반반
  P = 1:    반드시 일어남

이것이 확률론의 전부이다. 나머지는 이 아이디어를 정밀하게 발전시킨 것.
```

### 1.2 확률 vs 통계 — 방향이 반대다

```
확률 (Probability):
  규칙(모델)이 주어져 있을 때, 데이터가 어떻게 나올지 예측
  "공정한 동전이면, 100번 중 앞면은 약 50번" ← 모델 → 데이터

통계 (Statistics):
  데이터가 주어져 있을 때, 규칙(모델)이 무엇인지 추론
  "100번 중 앞면이 73번 나왔으면, 이 동전은 공정하지 않다" ← 데이터 → 모델

  모델 ──확률──→ 데이터
  모델 ←──통계── 데이터

둘은 역방향이지만, 같은 수학적 도구를 사용한다.
```

## 2. 확률의 기초 — 규칙 세우기

### 2.1 표본공간, 사건, 확률

```
🔴 [정의]
  표본공간 (sample space) Ω: 가능한 모든 결과의 집합
  사건 (event) A: 표본공간의 부분집합 (우리가 관심 있는 결과들)
  확률 P(A): 사건 A에 배정된 0~1 사이의 수

예시:
  동전 한 번 던지기: Ω = {앞, 뒤}
  주사위 한 번 던지기: Ω = {1, 2, 3, 4, 5, 6}
  사건 "짝수가 나온다": A = {2, 4, 6}
  P(A) = 3/6 = 1/2
```

### 2.2 확률의 공리 — 왜 이 세 가지인가

```
🔴 [정의 — 콜모고로프 공리]

  (1) P(A) ≥ 0                  모든 사건의 확률은 0 이상
  (2) P(Ω) = 1                  전체 확률은 1
  (3) 서로 배반인 사건 A, B에 대해:
      P(A ∪ B) = P(A) + P(B)   겹치지 않으면 확률은 더해진다

왜 이 세 가지로 충분한가:
  이 세 공리만으로 확률의 모든 성질을 유도할 수 있다.
  "확률이란 무엇인가"에 대한 최소한의 약속이다.
  
  확률을 "넓이"에 비유하면 직관적이다:
  - 넓이는 0 이상이다 (공리 1)
  - 전체 넓이는 1이다 (공리 2)
  - 겹치지 않는 영역의 넓이는 더하면 된다 (공리 3)
```

**공리에서 유도되는 것들:**

```
🟢 [유도 가능] — 공리 3개에서 모두 나온다:

P(Aᶜ) = 1 - P(A)
  왜: A와 Aᶜ는 서로 배반이고 A ∪ Aᶜ = Ω
  → P(A) + P(Aᶜ) = P(Ω) = 1
  → P(Aᶜ) = 1 - P(A)
  
  "비가 올 확률이 30%면, 안 올 확률은 70%"
  너무 당연하지만, 이것이 공리에서 논리적으로 따라 나온다는 것이 중요하다.

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  왜: A와 B가 겹치면, 겹친 부분이 두 번 더해지므로 한 번 빼야 한다.
  
  시각화:
  ┌─────────────────────┐
  │     A       B       │
  │   ┌───┬───┬───┐     │
  │   │   │A∩B│   │     │
  │   └───┴───┴───┘     │
  │  Ω                   │
  └─────────────────────┘
  
  A∩B(교집합) 부분이 P(A)에도, P(B)에도 포함되어 있으므로,
  단순히 더하면 두 번 세는 것이 된다. 한 번 빼서 보정한다.
  
  🔵 [CS 연결] 이것이 포함-배제 원리(Ch.06 조합론)의 확률 버전이다.
```

### 2.3 조건부 확률 — "알게 된 정보"를 반영하기

```
🔴 [정의]
  P(A|B) = P(A ∩ B) / P(B)     (P(B) > 0일 때)

  읽는 법: "B가 일어났다는 조건 하에서 A의 확률"
```

**왜 이 공식인가:**

```
B가 일어났다는 것을 "알게 되었다".
그러면 가능한 세계가 Ω 전체에서 B 안으로 줄어든다.

  ┌─────────────────────┐
  │         Ω           │       B가 일어나기 전: 전체 Ω가 가능
  │   ┌───┬───┬───┐     │
  │   │ A │A∩B│ B │     │       B가 일어난 후: B 안만 가능
  │   └───┴───┴───┘     │       A가 일어나려면 A∩B에 해당해야 함
  └─────────────────────┘

  새로운 "전체"가 B이므로:
  P(A|B) = (A∩B의 크기) / (B의 크기) = P(A∩B) / P(B)

  이것은 "표본공간을 B로 축소한 것"이다.
  축소된 공간에서 A에 해당하는 비율을 구하는 것.

예시:
  주사위를 던졌더니 짝수가 나왔다(B). 그것이 4 이상일 확률(A)?
  
  B = {2, 4, 6},  A = {4, 5, 6}
  A ∩ B = {4, 6}
  
  P(A|B) = P(A∩B) / P(B) = (2/6) / (3/6) = 2/3
  
  전체에서 보면 P(A) = 3/6 = 1/2이지만,
  "짝수"라는 정보를 얻은 후에는 2/3로 올라간다.
```

### 2.4 독립 — "정보가 도움이 안 된다"

```
🔴 [정의] A와 B가 독립(independent)이다 ⟺ P(A∩B) = P(A)·P(B)

동치 표현: P(A|B) = P(A)
  "B를 알아도 A의 확률이 변하지 않는다" = "B는 A에 대한 정보를 주지 않는다"

왜 이것이 중요한가:
  독립이면 동시확률을 개별 확률의 곱으로 분해할 수 있다.
  n개가 모두 독립이면: P(A₁∩A₂∩...∩Aₙ) = P(A₁)·P(A₂)·...·P(Aₙ)
  
  → 계산이 극적으로 단순해진다.
  → 통계학과 머신러닝에서 "iid(독립 동일 분포)" 가정을 하는 이유.

주의: 독립 ≠ 배반
  배반(mutually exclusive): A∩B = ∅ → 동시에 못 일어남
  독립(independent): P(A∩B) = P(A)P(B) → 서로 영향 없음
  
  사실 배반인 사건은 강하게 종속이다!
  A가 일어나면 B는 절대 안 일어나니까 → P(B|A) = 0 ≠ P(B)
```

## 3. 베이즈 정리 — 확률의 가장 강력한 도구

### 3.1 베이즈 정리란 — 왜 이것이 혁명적인가

```
🟢 [유도 가능] 조건부 확률의 정의에서 바로 나온다:

  P(A|B) = P(A∩B) / P(B)     ... (i)
  P(B|A) = P(A∩B) / P(A)     ... (ii)

  (ii)에서: P(A∩B) = P(B|A) · P(A)
  이것을 (i)에 대입:

  P(A|B) = P(B|A) · P(A) / P(B)    ← 베이즈 정리

  각 항의 이름:
  P(A|B):  사후확률 (posterior) — "데이터를 본 후의 믿음"
  P(B|A):  우도 (likelihood) — "A가 참일 때 이 데이터가 나올 확률"
  P(A):    사전확률 (prior) — "데이터를 보기 전의 믿음"
  P(B):    증거 (evidence) — "이 데이터가 나올 전체 확률" (정규화 상수)
```

**왜 혁명적인가:**

```
베이즈 정리는 "원인과 결과를 뒤집는" 공식이다.

  알고 있는 것:  결과(B)가 주어졌을 때의 관찰
  알고 싶은 것:  원인(A)이 무엇이었는가

  예시: 스팸 필터
    관찰(B): 메일에 "무료", "당첨" 같은 단어가 포함됨
    원인(A): 이 메일이 스팸인가?

    P(스팸|단어들) = P(단어들|스팸) · P(스팸) / P(단어들)

    P(단어들|스팸): 스팸 메일에 이 단어들이 나올 확률 → 데이터로부터 학습
    P(스팸): 전체 메일 중 스팸 비율 → 사전 지식
    P(단어들): 정규화 상수

  이것이 나이브 베이즈 분류기의 원리이다.

더 깊은 의미:
  베이즈 정리 = "새로운 증거를 보고 믿음을 갱신하는 규칙"
  
  사전확률(prior) + 새 데이터(likelihood) → 사후확률(posterior)
  
  → 사후확률이 다음의 사전확률이 된다 → 반복 → 점점 정확해짐
  → 이것이 "학습"의 수학적 형태이다
```

### 3.2 전확률 정리 — P(B) 구하기

```
🟢 [유도 가능] B₁, B₂, ..., Bₙ이 Ω의 분할(partition)이면:

  P(A) = Σᵢ P(A|Bᵢ) · P(Bᵢ)

왜 성립하는가:
  A가 일어나는 경우를 "어떤 Bᵢ 하에서 일어나는가"로 나눠 생각한다.
  
  A = (A∩B₁) ∪ (A∩B₂) ∪ ... (서로 배반)
  P(A) = P(A∩B₁) + P(A∩B₂) + ...
       = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + ...

예시:
  공장 A가 제품의 60%, 공장 B가 40%를 생산.
  A의 불량률 2%, B의 불량률 5%.
  
  전체 불량률 P(불량) = P(불량|A)·P(A) + P(불량|B)·P(B)
                     = 0.02 × 0.6 + 0.05 × 0.4
                     = 0.012 + 0.020 = 0.032 = 3.2%
```

## 4. 확률변수와 분포 — 불확실성에 구조를 부여하기

### 4.1 확률변수란 — 왜 필요한가

```
🔴 [정의] 확률변수(random variable) X: 표본공간 Ω → 실수 ℝ

  각 실험 결과에 숫자를 매기는 함수이다.

왜 필요한가:
  "동전 앞면"은 계산할 수 없지만, "앞면 = 1, 뒷면 = 0"으로 매기면
  평균, 분산 등 수학적 도구를 사용할 수 있다.
  
  확률변수는 "불확실한 결과를 숫자로 번역"하는 장치이다.

두 종류:
  이산(discrete): 셀 수 있는 값을 가짐 (주사위 눈, 동전 횟수)
  연속(continuous): 구간의 모든 실수를 가짐 (키, 온도, 시간)
```

### 4.2 PMF, PDF, CDF — 분포를 기술하는 세 가지 방법

```
🔴 [정의]

이산 확률변수:
  PMF (Probability Mass Function, 확률질량함수):
    p(x) = P(X = x)
    각 값이 일어날 확률. 모든 값에 대해 합하면 1.

연속 확률변수:
  PDF (Probability Density Function, 확률밀도함수):
    f(x) — P(a ≤ X ≤ b) = ∫[a,b] f(x) dx
    
    주의: f(x) 자체는 확률이 아니다! "확률의 밀도"이다.
    연속에서 P(X = 정확히 a) = 0이다. (점 하나의 넓이는 0)
    확률은 반드시 구간에 대해 적분해야 얻어진다.

    왜 P(X = 정확히 a) = 0인가:
      연속이면 가능한 값이 무한히 많다.
      각 값에 양의 확률을 주면 합이 무한대가 된다.
      따라서 각 "점"의 확률은 0이어야 한다.
      확률은 "점"이 아니라 "구간"에서만 의미를 갖는다.

둘 다:
  CDF (Cumulative Distribution Function, 누적분포함수):
    F(x) = P(X ≤ x)
    이산: F(x) = Σ_{xᵢ ≤ x} p(xᵢ)
    연속: F(x) = ∫[-∞, x] f(t) dt
    
    CDF와 PDF의 관계: F'(x) = f(x)
    → CDF를 미분하면 PDF (Ch.01 미적분의 기본정리!)
    → PDF를 적분하면 CDF
```

### 4.3 기댓값 — "장기적 평균"

```
🔴 [정의]
  이산: E[X] = Σ xᵢ · P(X = xᵢ) = Σ xᵢ · p(xᵢ)
  연속: E[X] = ∫[-∞,∞] x · f(x) dx

왜 이 형태인가:
  "각 값 × 그 값이 나올 확률"을 모두 더한다.
  자주 나오는 값에 더 큰 가중치를 준 가중평균(weighted average)이다.

  예시: 주사위
  E[X] = 1·(1/6) + 2·(1/6) + 3·(1/6) + 4·(1/6) + 5·(1/6) + 6·(1/6)
       = 21/6 = 3.5
  
  3.5는 실제로 나올 수 없는 값이지만,
  "여러 번 던졌을 때의 장기적 평균"이다.

🟢 [유도 가능] 기댓값의 선형성:
  E[aX + bY] = aE[X] + bE[Y]      ← 항상 성립 (독립 불필요!)

  왜: 기댓값은 적분(합)이고, 적분은 선형 연산이기 때문.
  이것은 기댓값의 정의에서 직접 유도된다.
  
  🔵 이것이 왜 유용한가:
  복잡한 확률변수의 기댓값을 간단한 부분으로 쪼개서 계산할 수 있다.
  예: 100개 주사위 합의 기댓값 = 100 × 3.5 = 350 (각각 계산할 필요 없음)
```

### 4.4 분산과 표준편차 — "얼마나 퍼져 있는가"

```
🔴 [정의]
  Var(X) = E[(X - μ)²]    여기서 μ = E[X]

  표준편차: σ = √Var(X)    (분산의 제곱근, 원래 단위로 복원)

왜 (X - μ)의 평균이 아니라 (X - μ)²인가:
  (X - μ)의 평균을 내면 양수와 음수가 상쇄되어 항상 0이 된다!
  E[X - μ] = E[X] - μ = μ - μ = 0
  
  상쇄를 피하기 위해 제곱을 한다.
  (|X - μ|의 평균을 쓸 수도 있지만, 절대값은 미분이 안 되어 수학적으로 불편)
  제곱은 미분 가능하고, 여러 좋은 수학적 성질을 가진다.
```

**분산의 계산 공식:**

```
🟢 [유도 가능]
  Var(X) = E[X²] - (E[X])²

  유도:
  Var(X) = E[(X-μ)²]
         = E[X² - 2μX + μ²]
         = E[X²] - 2μE[X] + μ²    (기댓값의 선형성)
         = E[X²] - 2μ² + μ²
         = E[X²] - μ²
         = E[X²] - (E[X])²

  이 공식이 왜 유용한가:
  E[(X-μ)²]을 직접 계산하려면 먼저 μ를 구하고 각 항에서 빼야 한다.
  E[X²] - (E[X])²은 E[X]와 E[X²]만 구하면 되므로 계산이 간편하다.

🟢 [유도 가능] 독립일 때:
  Var(X + Y) = Var(X) + Var(Y)    (독립일 때만!)

  왜: Var(X+Y) = E[(X+Y)²] - (E[X+Y])²을 전개하면
  교차항 E[XY] - E[X]E[Y] = Cov(X,Y)가 나오는데,
  독립이면 Cov(X,Y) = 0이므로 사라진다.
```

## 5. 주요 분포들 — 왜 이 분포들이 중요한가

### 5.1 이산 분포

```
🔴 [외워야 할 분포들 — 각각이 특정 자연현상을 모델링]

베르누이 분포 Bernoulli(p):
  "성공(1) 또는 실패(0), 한 번의 시행"
  P(X=1) = p,  P(X=0) = 1-p
  E[X] = p,  Var(X) = p(1-p)
  
  → 가장 단순한 확률 모델. 동전 던지기.

이항 분포 Binomial(n, p):
  "n번 독립 시행에서 성공 횟수"
  P(X=k) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ
  E[X] = np,  Var(X) = np(1-p)

  왜 이 형태인가:
    n번 중 정확히 k번 성공하려면:
    - k번 성공할 확률: pᵏ
    - (n-k)번 실패할 확률: (1-p)ⁿ⁻ᵏ
    - k번을 어떤 위치에 배치할지: C(n,k)가지
    → 세 가지를 곱한다.
  
  🟢 이항분포는 베르누이의 합이다:
    X = X₁ + X₂ + ... + Xₙ (각 Xᵢ ~ Bernoulli(p), 독립)
    E[X] = nE[Xᵢ] = np (기댓값의 선형성)

포아송 분포 Poisson(λ):
  "단위 시간/공간에서 사건이 일어나는 횟수"
  P(X=k) = (λᵏ · e⁻λ) / k!
  E[X] = λ,  Var(X) = λ  (평균 = 분산인 특이한 분포)

  왜 이 형태인가:
    이항분포에서 n→∞, p→0, np=λ(일정)이면 포아송에 수렴한다.
    "매우 드문 사건이 매우 많은 기회에서 일어나는" 상황.

  🔵 [CS 연결]
    웹 서버에 1초당 들어오는 요청 수 → Poisson
    해시 테이블의 한 버킷에 들어가는 키 수 → Poisson
    텍스트에서 특정 단어의 출현 횟수 → Poisson

기하 분포 Geometric(p):
  "첫 성공까지 필요한 시행 횟수"
  P(X=k) = (1-p)ᵏ⁻¹ · p
  E[X] = 1/p

  왜: k번째에 처음 성공하려면, k-1번 연속 실패 후 1번 성공.
  
  🔵 쿠폰 수집 문제: n종류 쿠폰을 모두 모으는 데 필요한 횟수
    ≈ n·(1 + 1/2 + 1/3 + ... + 1/n) = n·H_n ≈ n·ln(n)
    → 기하분포의 합으로 유도된다
```

### 5.2 연속 분포

```
균등 분포 Uniform(a, b):
  "모든 값이 동일한 확률"
  f(x) = 1/(b-a)  (a ≤ x ≤ b일 때)
  E[X] = (a+b)/2,  Var(X) = (b-a)²/12

  왜 f(x) = 1/(b-a)인가:
    모든 점에서 같은 밀도. 전체 구간의 넓이가 1이 되려면:
    f(x) · (b-a) = 1 → f(x) = 1/(b-a)

  🔵 [CS 연결] 난수 생성의 기초. 모든 랜덤 분포는 균등분포에서 변환.
```

**정규 분포 — 왜 이것이 "가장 중요한 분포"인가:**

```
🔴 [외워야 할 분포] 정규(가우시안) 분포 N(μ, σ²):

  f(x) = (1 / (σ√(2π))) · e^(-(x-μ)² / (2σ²))

  E[X] = μ,  Var(X) = σ²

이 공식이 왜 이렇게 복잡하게 생겼는가:

  핵심은 e^(-x²) 부분이다. 나머지는 조정이다.

  (1) e^(-(x-μ)²/(2σ²)):
      μ에서 멀어질수록 확률 밀도가 급격히 감소한다.
      σ가 클수록 느리게 감소(넓게 퍼짐), 작을수록 빠르게 감소(좁게 집중).
      
      왜 e^(-x²)인가:
      "중심에서의 거리의 제곱에 비례하여 로그확률이 감소하는" 유일한 분포.
      → 최대 엔트로피 원리: 평균과 분산만 알 때 가장 불확실한(가정이 적은) 분포.

  (2) 1/(σ√(2π)):
      정규화 상수. ∫[-∞,∞] f(x) dx = 1이 되도록 맞추는 것.
      √(2π)가 등장하는 이유: ∫[-∞,∞] e^(-x²/2) dx = √(2π)
      (→ Ch.01의 가우스 적분, 극좌표 변환으로 증명)

왜 정규분포가 어디서나 나타나는가:

  🔴 중심극한정리 (Central Limit Theorem, CLT):
  "독립인 확률변수들의 합(평균)은, 원래 분포가 뭐든,
   개수가 충분히 많으면 정규분포에 가까워진다."

  X₁, X₂, ..., Xₙ이 iid이고 E[Xᵢ]=μ, Var(Xᵢ)=σ²이면:
  
  X̄ = (X₁+...+Xₙ)/n 의 분포 → N(μ, σ²/n)  (n이 클수록 정확)
  
  또는 동등하게:
  (X̄ - μ) / (σ/√n) → N(0, 1)  (표준정규분포로 수렴)

  왜 이것이 성립하는가 (직관):
    각 Xᵢ가 평균보다 클 수도, 작을 수도 있다.
    많이 더하면 큰 것과 작은 것이 서로 상쇄되어 평균 근처에 모인다.
    극단적으로 큰(작은) 합이 되려면 모든 Xᵢ가 동시에 극단적이어야 하므로
    확률이 급격히 감소한다 → 종 모양(bell curve)이 된다.

  🔵 [CS 연결]
    해싱: 많은 키의 해시값 합 → 정규분포 근사
    머신러닝: 가중치 초기화를 정규분포로 하는 이유
    A/B 테스팅: 표본 평균의 분포가 정규 → z-검정, t-검정의 근거
    오차 모델: 측정 오차 = 많은 작은 요인의 합 → 정규분포
```

```
지수 분포 Exponential(λ):
  "사건 사이의 대기 시간"
  f(x) = λe^(-λx)  (x ≥ 0)
  E[X] = 1/λ,  Var(X) = 1/λ²

  포아송과의 관계:
    단위 시간당 사건 수 ~ Poisson(λ)이면,
    사건 간 대기 시간 ~ Exponential(λ)
    
    같은 현상의 두 가지 관점이다.

  🔴 무기억성 (memoryless property):
    P(X > s+t | X > s) = P(X > t)
    
    "이미 s만큼 기다렸다는 사실이 남은 대기 시간에 영향을 주지 않는다"
    
    왜 이 성질을 가지는가:
    지수함수의 성질: e^(-λ(s+t)) / e^(-λs) = e^(-λt)
    
    🔵 이것이 연속 분포 중 무기억성을 가진 유일한 분포이다.
    (이산에서는 기하분포가 유일)
```

## 6. 결합분포와 공분산 — 여러 변수의 관계

### 6.1 결합분포 — 왜 필요한가

```
하나의 확률변수만으로는 부족하다.
"키가 180cm인 사람의 몸무게는?"처럼 두 변수의 관계를 다루려면
결합분포(joint distribution)가 필요하다.

🔴 [정의]
  결합 PMF: p(x, y) = P(X=x, Y=y)
  결합 PDF: f(x, y) — P(a≤X≤b, c≤Y≤d) = ∫∫ f(x,y) dx dy

주변분포(marginal): 한 변수를 "무시"한 분포
  p_X(x) = Σ_y p(x, y)           (이산)
  f_X(x) = ∫[-∞,∞] f(x, y) dy    (연속)

  왜 이런 형태: y의 모든 가능한 값에 대해 합산/적분하면 y를 제거할 수 있다.
```

### 6.2 공분산과 상관계수 — 함께 변하는 정도

```
🔴 [정의]
  Cov(X, Y) = E[(X - μₓ)(Y - μᵧ)] = E[XY] - E[X]E[Y]

  Corr(X, Y) = ρ = Cov(X,Y) / (σₓ · σᵧ)    (-1 ≤ ρ ≤ 1)

공분산이 양수: X가 클 때 Y도 크는 경향
공분산이 음수: X가 클 때 Y는 작은 경향
공분산이 0: 선형 관계 없음 (주의: 비선형 관계는 있을 수 있음!)

왜 Cov(X,Y) = E[XY] - E[X]E[Y]인가:
  🟢 Var(X) 유도와 완전히 같은 방식:
  Cov(X,Y) = E[(X-μₓ)(Y-μᵧ)]
           = E[XY - μₓY - Xμᵧ + μₓμᵧ]
           = E[XY] - μₓE[Y] - E[X]μᵧ + μₓμᵧ
           = E[XY] - μₓμᵧ
           = E[XY] - E[X]E[Y]
  
  독립이면 E[XY] = E[X]E[Y]이므로 Cov = 0.
  역은 성립 안 함: Cov = 0이어도 독립이 아닐 수 있음 (비선형 관계).

🔵 [CS 연결]
  공분산 행렬: 여러 변수의 공분산을 행렬로 정리
  → PCA(Ch.02)의 입력이 된다
  → 가우시안 분포의 형태를 결정한다
  → 포트폴리오 이론(금융)에서 리스크 분산에 사용
```

## 7. 큰 수의 법칙 — 왜 경험이 쌓이면 정확해지는가

```
🔴 [정리] 큰 수의 법칙 (Law of Large Numbers, LLN):

  X₁, X₂, ..., Xₙ이 iid이고 E[Xᵢ] = μ이면:
  
  X̄ₙ = (X₁ + ... + Xₙ)/n → μ  (n → ∞)

  "표본 평균은 참 평균에 수렴한다"

왜 이것이 성립하는가 (직관):
  각 Xᵢ는 μ 주위에서 변동한다.
  양의 변동과 음의 변동이 독립이므로, 많이 더할수록 상쇄된다.
  평균을 내면 변동이 줄어들고, n이 충분히 크면 거의 μ에 도달한다.
  
  정량적으로: Var(X̄ₙ) = σ²/n → 0  (n → ∞)
  분산이 0으로 가므로 X̄ₙ이 μ에 집중된다.

🔵 [CS 연결]
  몬테카를로 시뮬레이션: 충분히 많이 샘플링하면 참값에 수렴
  해시 테이블: 키가 많을수록 부하율이 예측 가능해짐
  A/B 테스팅: 사용자가 많을수록 실험 결과가 안정적
```

## 8. 통계적 추론 — 데이터에서 세상을 읽기

### 8.1 점 추정 — 모수를 하나의 값으로 추정

```
모수(parameter) θ: 모집단의 특성을 기술하는 값 (예: 평균 μ, 분산 σ²)
추정량(estimator) θ̂: 표본으로부터 θ를 추정하는 함수

좋은 추정량의 조건:
  불편성(unbiased): E[θ̂] = θ  (평균적으로 정확)
  일치성(consistent): n→∞이면 θ̂ → θ  (데이터가 많으면 정확해짐)
  효율성(efficient): 분산이 작을수록 좋다
```

**최대우도추정 (MLE) — 가장 널리 쓰이는 추정법:**

```
🔴 [정의]
  θ̂_MLE = argmax_θ L(θ) = argmax_θ P(data | θ)

  "관찰된 데이터가 가장 그럴듯하게(likely) 나오는 θ를 선택한다"

왜 이것이 합리적인가:
  여러 가능한 θ 중에서, 실제로 본 데이터를 가장 잘 설명하는 θ를 고른다.
  "가장 그럴듯한 설명을 채택한다"는 상식적 원칙의 수학적 표현.

실전에서는 log를 취한다:
  θ̂_MLE = argmax_θ log L(θ) = argmax_θ Σᵢ log P(xᵢ | θ)
  
  왜 log를 쓰는가:
  (1) 곱셈이 덧셈으로 바뀌어 계산이 편하다
  (2) 수치적으로 안정하다 (곱이 매우 작은 수가 되는 언더플로 방지)
  (3) log는 단조증가이므로 최대점이 바뀌지 않는다

예시: 동전의 앞면 확률 p 추정
  n번 중 k번 앞면:
  L(p) = C(n,k) · pᵏ · (1-p)ⁿ⁻ᵏ
  log L(p) = const + k·log(p) + (n-k)·log(1-p)
  d/dp [log L] = k/p - (n-k)/(1-p) = 0
  → p̂ = k/n
  
  직관적으로도 당연하다: 앞면이 k번 나왔으면 p ≈ k/n.
  MLE는 이 직관을 수학적으로 정당화한다.

🔵 [CS 연결]
  로지스틱 회귀의 학습 = MLE (크로스 엔트로피 최소화 = log-likelihood 최대화)
  언어 모델의 학습 = 다음 토큰의 MLE
  → 딥러닝의 손실 함수 상당수가 MLE에서 유도된다
```

### 8.2 구간 추정 — 추정의 불확실성 표현

```
🔴 [정의] 95% 신뢰구간:
  "이 방법으로 구간을 만들면, 100번 중 약 95번은 참값을 포함한다"

  정규분포 가정 하 평균의 95% 신뢰구간:
  X̄ ± 1.96 · σ/√n

왜 1.96인가:
  표준정규분포에서 P(-1.96 < Z < 1.96) ≈ 0.95
  이것은 정규분포표에서 나오는 값이다. 🔴 외워야 한다.
  (대략 2라고 기억해도 실용적으로 충분하다)

왜 √n으로 나누는가:
  표본 평균의 표준편차(표준오차) = σ/√n
  n이 커질수록 표준오차가 줄어듦 → 구간이 좁아짐 → 더 정밀한 추정
  
  🔵 [CS 연결]
  A/B 테스팅에서 "통계적으로 유의한 차이인가"를 판단할 때 사용
  n이 4배가 되면 구간이 절반으로 → 정밀도 2배에 데이터 4배 필요
```

### 8.3 가설 검정 — 증거 기반 의사결정

```
🔴 [정의]
  H₀ (귀무가설): "차이가 없다", "효과가 없다" — 현재 상태 유지
  H₁ (대립가설): "차이가 있다", "효과가 있다" — 새로운 주장

절차:
  1. H₀를 가정한다
  2. H₀가 참일 때 관찰된 데이터가 나올 확률(p-value)을 계산한다
  3. p-value < α (유의수준, 보통 0.05)이면 H₀를 기각한다

p-value의 정확한 의미:
  "H₀가 참이라고 가정할 때, 관찰된 것만큼 또는 더 극단적인
   데이터가 나올 확률"
  
  p-value가 작다 = "H₀가 참이면 이런 데이터는 매우 드물다"
                  = "H₀가 거짓일 가능성이 높다"
  
  주의: p-value ≠ P(H₀가 참 | 데이터)!
        p-value = P(데이터 | H₀가 참)
        이 둘은 완전히 다르다. (베이즈 정리를 봐야 전자를 구할 수 있다)

두 가지 오류:
  1종 오류 (Type I, α): H₀가 참인데 기각 → "없는 효과를 있다고 함"
  2종 오류 (Type II, β): H₀가 거짓인데 채택 → "있는 효과를 못 찾음"
  
  α를 줄이면 β가 증가 (트레이드오프)
  n(표본 크기)을 키우면 둘 다 줄일 수 있다

🔵 [CS 연결]
  A/B 테스팅: 새 디자인이 클릭률을 높이는가? → 가설 검정
  이상 탐지: 이 데이터가 정상 분포에서 나왔을 가능성이 낮은가?
  모델 비교: 두 모델의 성능 차이가 유의한가?
```

## 9. 베이즈 추론 — 사전 지식 + 데이터 = 업데이트된 믿음

### 9.1 빈도주의 vs 베이즈주의

```
빈도주의 (Frequentist):
  θ는 고정된 상수. 데이터가 확률적.
  "동전의 진짜 확률 p = 0.5인가, 아닌가"
  → 추정량 θ̂의 성질(불편성, 일치성)에 집중

베이즈주의 (Bayesian):
  θ도 확률변수. θ에 대한 "믿음의 정도"가 확률.
  "데이터를 보기 전: p가 0.5일 확률 50%, 0.7일 확률 20%, ..."
  "데이터를 본 후: p가 0.5일 확률 30%, 0.7일 확률 40%, ..."
  → 사전분포가 데이터로 업데이트되어 사후분포가 되는 과정에 집중

핵심 차이:
  빈도: P(data | θ) → θ를 추정
  베이즈: P(θ | data) ∝ P(data | θ) · P(θ) → θ의 분포를 추정
```

### 9.2 MAP 추정 — MLE + 사전지식

```
🔴 [정의] MAP (Maximum A Posteriori):
  θ̂_MAP = argmax_θ P(θ | data) = argmax_θ P(data|θ) · P(θ)

  MLE와의 관계:
  MLE = argmax P(data|θ)              ← 우도만 최대화
  MAP = argmax P(data|θ) · P(θ)      ← 우도 × 사전확률 최대화

  P(θ) = 균등분포(모든 θ에 같은 확률)이면 MAP = MLE
  → MLE는 "사전 지식 없는 MAP"의 특수한 경우

🔵 [CS 연결]
  MAP에서 P(θ)로 정규분포를 쓰면:
  log P(θ) ∝ -‖θ‖²  → L2 정규화!
  
  즉 L2 정규화 = "파라미터가 0 근처에 있을 것이라는 사전 믿음"
  MLE + L2 정규화 = MAP 추정
  → 정규화의 확률적 해석
```

## 10. 회귀 분석 — 변수 간 관계 모델링

### 10.1 선형 회귀 — 왜 이것이 기본인가

```
🔴 [모델] y = β₀ + β₁x + ε    (ε ~ N(0, σ²))

  y: 반응변수 (예측하려는 것)
  x: 설명변수 (예측에 사용하는 것)
  β₀: 절편 (y-intercept)
  β₁: 기울기 (x가 1 증가할 때 y의 변화)
  ε: 오차 (모델이 설명하지 못하는 부분)

왜 "선형"인가:
  파라미터(β)에 대해 선형이라는 뜻이다.
  y = β₀ + β₁x²도 선형 회귀이다 (x²을 새 변수로 보면).

최소자승법(OLS):
  Σ(yᵢ - ŷᵢ)²을 최소화하는 β₀, β₁을 찾는다.

  왜 제곱을 쓰는가:
  - 양수/음수 오차의 상쇄 방지 (분산과 같은 이유)
  - 미분 가능하여 닫힌 해(closed-form solution)를 구할 수 있다
  - 오차가 정규분포이면 MLE와 일치한다

🟢 [유도 가능] 행렬 형태:
  y = Xβ + ε
  β̂ = (XᵀX)⁻¹Xᵀy    ← 정규방정식 (normal equation)
  
  이것은 ∂/∂β [‖y - Xβ‖²] = 0을 풀면 나온다.
  (Ch.01 미적분의 최적화 + Ch.02 선형대수의 행렬 연산의 조합)
```

## 12. 정리 — 확률통계를 관통하는 원리

```
[원리 1] 확률 = 불확실성의 측정 (0~1 사이 숫자)
  → 공리 3개에서 모든 성질이 유도됨

[원리 2] 조건부 확률 = 새 정보로 확률 갱신
  → P(A|B) = P(A∩B)/P(B)

[원리 3] 베이즈 정리 = 원인과 결과를 뒤집기
  → 사후확률 ∝ 우도 × 사전확률

[원리 4] 기댓값 = 가중평균
  → 선형성이라는 강력한 성질

[원리 5] 분산 = 퍼짐 정도 (제곱 편차의 평균)
  → 독립이면 합의 분산 = 분산의 합

[원리 6] CLT = 합/평균은 정규분포에 수렴
  → 정규분포가 어디서나 나타나는 이유

[원리 7] MLE = "가장 그럴듯한 설명"
  → 데이터가 가장 잘 나오는 파라미터 선택

외워야 할 것:
  🔴 확률의 3 공리, 조건부 확률 정의, 독립 정의
  🔴 주요 분포의 PMF/PDF, 기댓값, 분산
  🔴 CLT의 진술
  🔴 1.96 (95% 신뢰구간의 z값)

유도할 수 있는 것:
  🟢 베이즈 정리 (조건부 확률 정의에서)
  🟢 기댓값의 선형성 (적분의 선형성에서)
  🟢 Var(X) = E[X²] - (E[X])² (정의 전개)
  🟢 정규방정식 β̂ = (XᵀX)⁻¹Xᵀy (미분 = 0)
  🟢 MLE에서 L2 정규화 = MAP (사전분포가 정규)
```
