### 읽기 예시

```
Ax = b
→ "행렬 A에 벡터 x를 곱한 것이 벡터 b와 같다"

det(A) = 0
→ "A의 행렬식(디터미넌트)이 0이다"

Av = λv
→ "A에 v를 곱하면 람다 곱하기 v가 된다"
→ "v는 A의 고유벡터이고, λ는 대응하는 고유값이다"

‖v‖ = √(v₁² + v₂² + ... + vₙ²)
→ "벡터 v의 노름(크기)은 각 성분 제곱합의 제곱근이다"

A = UΣVᵀ
→ "A는 U 시그마 V트랜스포즈로 분해된다" (특이값 분해, SVD)
```

## 1. 출발점: 선형대수는 왜 존재하는가

### 1.1 "선형"이란 무엇인가

선형대수의 모든 것은 **"선형성(linearity)"**이라는 하나의 성질에서 출발한다.

```
🔴 [정의] 함수 T가 선형(linear)이다 ⟺ 두 가지 성질을 동시에 만족한다:

  (1) T(u + v) = T(u) + T(v)          가산성 (additivity)
  (2) T(c·u) = c·T(u)                  동차성 (homogeneity)

  합쳐서 하나로: T(c₁u + c₂v) = c₁T(u) + c₂T(v)

이것이 전부다. 선형대수 전체가 이 성질을 탐구하는 학문이다.
```

**왜 "선형"이 그토록 중요한가:**

```
선형이면:
  - 부분을 알면 전체를 안다 (중첩 원리, superposition)
    T(3u + 2v) = 3T(u) + 2T(v) — 부분 결과를 합치면 전체 결과
  - 복잡한 것을 단순한 조각으로 분해할 수 있다
  - 행렬 곱셈 하나로 모든 것을 표현할 수 있다
    → 컴퓨터가 매우 빠르게 계산 가능 (GPU가 행렬 곱에 특화)

비선형이면:
  - 부분의 합 ≠ 전체. T(u+v) ≠ T(u)+T(v)
  - 일반적인 풀이법이 존재하지 않음
  - 각 경우를 개별적으로 분석해야 함

현실은 대부분 비선형이지만:
  국소적으로는 선형 근사가 가능하다.
  (→ Ch.01의 미분이 바로 이것: 곡선을 접선(=선형)으로 근사)
  
  딥러닝 = 선형 변환(행렬 곱) + 비선형 활성화 함수의 반복
  → 선형과 비선형을 번갈아 쌓아서 복잡한 함수를 표현
```

### 1.2 왜 CS에서 선형대수가 핵심인가

```
컴퓨터가 가장 잘하는 연산: 숫자 배열에 대한 규칙적인 반복 계산
행렬 연산: 숫자 배열에 대한 가장 체계적인 반복 계산

→ 선형대수는 "컴퓨터의 언어에 가장 가까운 수학"이다.

┌───────────────────┬─────────────────────────────────────────┐
│ CS 분야             │ 선형대수가 쓰이는 방식                     │
├───────────────────┼─────────────────────────────────────────┤
│ 딥러닝 (전 과정)    │ 모든 층: y = Wx + b (행렬 곱 + 벡터 합)   │
│ 3D 그래픽          │ 회전, 확대, 이동 = 4×4 행렬 곱             │
│ 검색 엔진           │ PageRank = 거대 행렬의 고유벡터             │
│ 추천 시스템         │ 사용자×아이템 행렬 → SVD로 분해            │
│ 데이터 압축         │ PCA, SVD로 차원 축소                      │
│ 컴퓨터 비전         │ 이미지 = 행렬, 필터 = 행렬 연산             │
│ 양자 컴퓨팅         │ 상태 = 벡터, 게이트 = 유니터리 행렬         │
│ 로보틱스           │ 관절 변환 = 행렬 체인 곱                    │
│ 자연어 처리         │ 단어 임베딩 = 벡터, 어텐션 = 행렬 연산       │
└───────────────────┴─────────────────────────────────────────┘
```

## 2. 벡터 — 선형대수의 기본 단위

### 2.1 벡터란 무엇인가

```
벡터를 이해하는 세 가지 관점:

관점 1: 화살표 (기하학적)
  크기(magnitude)와 방향(direction)을 가진 양.
  → (3, 4)는 x방향으로 3, y방향으로 4 이동하는 화살표
  → 크기 = √(3² + 4²) = 5

관점 2: 숫자 목록 (데이터 과학적)
  순서가 있는 숫자 n개의 묶음.
  → 학생 한 명 = (수학 90, 영어 85, 키 175) — 3차원 벡터

관점 3: 벡터 공간의 원소 (추상적, 가장 강력)
  덧셈과 스칼라 곱이 정의된 대상이면 무엇이든 벡터.
  → 숫자 배열, 함수, 다항식, 행렬 모두 벡터가 될 수 있다!

세 번째 관점이 왜 강력한가:
  같은 이론 하나로 숫자 배열도, 함수도, 신호도 다룰 수 있다.
  "벡터"라는 이름표를 붙일 수 있으면 선형대수의 모든 도구가 작동한다.
```

### 2.2 벡터 공간 — 벡터가 사는 세계의 규칙

```
🔴 [정의] 벡터 공간(vector space) V란:
  "벡터 덧셈과 스칼라 곱이 상식적으로 작동하는 집합"이다.

공리 10개가 있지만, 핵심은 두 가지:
  (1) 벡터끼리 더할 수 있고, 결과도 같은 공간에 속한다
  (2) 벡터에 숫자(스칼라)를 곱할 수 있고, 결과도 같은 공간에 속한다

나머지 공리들(교환법칙, 결합법칙, 영벡터 존재 등)은
"덧셈과 스칼라 곱이 우리가 기대하는 대로 행동한다"를 보장할 뿐이다.

왜 이 정의가 중요한가:
  이 규칙을 만족하는 어떤 집합이든 "벡터 공간"이라 부를 수 있고,
  선형대수의 모든 정리가 자동으로 적용된다.
  
  ℝⁿ (숫자 벡터)에서 증명한 것이
  함수 공간에서도 그대로 성립한다 → 엄청난 효율
```

### 2.3 내적 — 두 벡터가 얼마나 "같은 방향"인가

```
🔴 [정의] ℝⁿ에서의 표준 내적:
  u · v = u₁v₁ + u₂v₂ + ... + uₙvₙ = Σᵢ uᵢvᵢ
```

**왜 이 공식이 "같은 방향 정도"를 측정하는가:**

```
기하학적 해석:
  u · v = ‖u‖ · ‖v‖ · cos(θ)      (θ는 두 벡터 사이의 각도)

이 등식이 성립하는 이유 — 코사인 법칙에서 유도:

  삼각형의 세 변: u, v, u-v
  코사인 법칙: ‖u-v‖² = ‖u‖² + ‖v‖² - 2‖u‖‖v‖cos(θ)
  
  좌변을 성분으로 전개:
  ‖u-v‖² = Σ(uᵢ-vᵢ)² = Σuᵢ² - 2Σuᵢvᵢ + Σvᵢ²
         = ‖u‖² - 2(u·v) + ‖v‖²
  
  코사인 법칙 우변과 비교:
  ‖u‖² - 2(u·v) + ‖v‖² = ‖u‖² + ‖v‖² - 2‖u‖‖v‖cos(θ)
  
  따라서: u · v = ‖u‖‖v‖cos(θ)  🟢 [유도 완료]

이것이 알려주는 것:
  cos(θ) = 1 (θ=0°, 같은 방향)   → 내적 최대
  cos(θ) = 0 (θ=90°, 수직)       → 내적 = 0, "직교(orthogonal)"
  cos(θ) = -1 (θ=180°, 반대 방향) → 내적 최소(음수)

🔵 [CS 연결] 코사인 유사도:
  cos(θ) = (u · v) / (‖u‖ · ‖v‖)
  
  NLP: 단어 벡터 "king"과 "queen"의 코사인 유사도가 높다
       → 의미적으로 비슷한 단어는 비슷한 방향을 가리킨다
  추천: 사용자 A의 취향 벡터와 사용자 B의 취향 벡터가 비슷한 방향
       → 같은 것을 추천해도 좋다
```

### 2.4 노름 — 벡터의 "크기"

```
🔴 [정의] L2 노름 (유클리드 노름):
  ‖v‖ = √(v₁² + v₂² + ... + vₙ²) = √(v · v)

왜 이 형태인가: 피타고라스 정리의 n차원 확장이다.
  2차원: ‖(a,b)‖ = √(a² + b²)     ← 직각삼각형의 빗변
  3차원: ‖(a,b,c)‖ = √(a² + b² + c²)  ← 3D 대각선
  n차원: 같은 패턴의 자연스러운 확장

다른 노름들과 왜 필요한가:
  L1 노름: ‖v‖₁ = |v₁| + |v₂| + ... + |vₙ|  (맨해튼 거리)
  L∞ 노름: ‖v‖∞ = max(|v₁|, |v₂|, ..., |vₙ|)
  
  🔵 머신러닝에서:
  L2 정규화: 가중치를 작게 유지 → 과적합 방지 (Ridge)
  L1 정규화: 가중치를 0으로 만듦 → 특성 선택 효과 (Lasso)
  
  L1이 0을 만드는 이유:
  L1의 등고선은 마름모 형태 → 꼭짓점(축 위)에서 만나기 쉬움
  L2의 등고선은 원 형태 → 축 위에서 만날 특별한 이유 없음
```

## 3. 행렬 — 선형 변환을 숫자로 기록한 것

### 3.1 행렬의 진짜 정체 — 왜 이런 형태인가

```
🔴 [핵심 통찰]
  행렬은 "선형 변환을 숫자로 표현한 것"이다.
  
  행렬 자체가 목적이 아니다.
  선형 변환이 본질이고, 행렬은 그것을 기록하는 방법이다.
```

**선형 변환이란:**

```
T: ℝⁿ → ℝᵐ인 선형 함수

예시: T가 2차원 벡터를 시계 방향으로 90° 회전시키는 변환이라면
  T(1, 0) = (0, -1)     ← x축 단위벡터 → 아래로
  T(0, 1) = (1, 0)      ← y축 단위벡터 → 오른쪽으로

T가 선형이므로, 임의의 벡터 (a, b)에 대해:
  T(a, b) = T(a·(1,0) + b·(0,1))
          = a·T(1,0) + b·T(0,1)     ← 선형성!
          = a·(0,-1) + b·(1,0)
          = (b, -a)

핵심: 단위벡터들에 대한 결과만 알면, 모든 벡터에 대한 결과를 안다.
     이것이 선형성의 힘이다.
```

**행렬이 탄생하는 순간:**

```
T(1,0)과 T(0,1)의 결과를 열(column)로 나란히 세우면 → 행렬!

  A = [ T(e₁) | T(e₂) ]
    = [ 0   1 ]
      [ -1  0 ]

그러면 임의의 벡터에 대한 변환은 행렬 곱으로 표현된다:

  T(v) = A · v

  [ 0   1 ] · [ a ] = [ b  ]
  [ -1  0 ]   [ b ]   [ -a ]

이것이 행렬 곱셈이 이렇게 생긴 이유이다!
  행렬의 각 열 = 각 단위벡터가 어디로 가는지
  행렬 곱 = 그 결과들을 입력 성분의 가중치로 합산

왜 "행 × 열"로 곱하는가:
  결과의 i번째 성분 = (A의 i번째 행) · (입력 벡터)
  = "i번째 출력이 입력의 각 성분에 얼마나 의존하는가"의 가중합
```

### 3.2 행렬 곱셈 — 왜 AB ≠ BA인가

```
🔴 [외워야 할 사실] 행렬 곱셈은 교환법칙이 성립하지 않는다.
  AB ≠ BA (일반적으로)

왜: 행렬 곱은 "변환의 합성"이기 때문이다.

  A = 회전, B = 확대라고 하면:
  AB: "먼저 확대, 그다음 회전"
  BA: "먼저 회전, 그다음 확대"
  
  결과가 다르다!
  
  일상적 비유:
    "양말 신고 신발 신기" ≠ "신발 신고 양말 신기"
    순서가 중요한 작업은 교환할 수 없다.

🟢 [유도 가능] 반면, 결합법칙은 성립한다:
  (AB)C = A(BC)
  
  왜: 세 번 변환한 최종 결과는 괄호 위치에 상관없이 같으니까.
  "양말 → 신발 → 코트"의 최종 결과는 하나.
```

### 3.3 전치 — 행과 열을 뒤바꾸기

```
🔴 [정의] 전치 행렬 Aᵀ: A의 (i,j) 원소가 Aᵀ의 (j,i) 원소가 된다.

  A = [ 1  2  3 ]     Aᵀ = [ 1  4 ]
      [ 4  5  6 ]          [ 2  5 ]
                            [ 3  6 ]

왜 전치가 중요한가:
  내적을 행렬 곱으로 쓸 수 있다: u · v = uᵀv
  
  u = [u₁]    uᵀ = [u₁ u₂ u₃]
      [u₂]
      [u₃]
  
  uᵀv = [u₁ u₂ u₃] · [v₁] = u₁v₁ + u₂v₂ + u₃v₃ = u · v
                       [v₂]
                       [v₃]

🟢 [유도 가능] 전치의 성질:
  (AB)ᵀ = BᵀAᵀ   ← 순서가 뒤집힌다!
  
  왜: "양말 신고 신발 신는 것을 되돌리려면 신발 먼저 벗고 양말 벗기"
  합성의 역 = 역의 역순 합성. 전치에도 같은 원리가 적용된다.
```

## 4. 연립방정식 — 선형대수의 첫 번째 응용

### 4.1 왜 연립방정식이 행렬과 관련되는가

```
연립방정식:
  2x + 3y = 8
  4x + 1y = 6

이것을 행렬로 쓰면:
  [ 2  3 ] · [ x ] = [ 8 ]
  [ 4  1 ]   [ y ]   [ 6 ]

  즉 Ax = b

왜 이렇게 쓰는가:
  행렬 곱의 정의에 의해, A의 각 행과 x의 내적이 b의 각 성분이 된다.
  1행: 2x + 3y = 8  ← A의 1행 · x = b의 1성분
  2행: 4x + 1y = 6  ← A의 2행 · x = b의 2성분
  
  → 연립방정식 = 행렬 방정식. 같은 것의 다른 표현.
  → n개의 방정식을 하나의 식 Ax = b로 압축.
```

### 4.2 가우스 소거법 — 왜 이 방법이 작동하는가

```
🟢 [유도 가능] 핵심 원리:

  방정식의 양변에 같은 수를 더하거나, 같은 수를 곱해도
  해는 변하지 않는다.

  "3x = 6"과 "x = 2"는 같은 해를 가진다 (양변을 3으로 나눔).
  "x + y = 5"와 "2x + 2y = 10"은 같은 해를 가진다 (양변에 2를 곱함).

  가우스 소거법은 이 원리를 체계적으로 반복 적용하는 것이다:
  1. 한 행에 상수를 곱해 다른 행에서 빼서, 변수를 하나씩 소거
  2. 사다리꼴(echelon form)로 만든 후 역대입

  [ 2  3 | 8 ]  →  [ 2  3 | 8  ]  →  [ 2  3 | 8 ]
  [ 4  1 | 6 ]     [ 0 -5 | -10]     [ 0  1 | 2  ]
  
  2행에서 1행×2를 뺌     2행을 -5로 나눔
  
  → y = 2, 역대입하면 2x + 6 = 8, x = 1

왜 이것이 중요한가:
  n개의 변수, n개의 방정식을 O(n³)에 풀 수 있다.
  컴퓨터가 아무리 큰 연립방정식도 체계적으로 풀 수 있는 근거.
```

### 4.3 해의 존재와 유일성 — 언제 풀 수 있고, 언제 못 푸는가

```
Ax = b의 해:

  Case 1: 유일한 해 — 직선 2개가 한 점에서 만남
  Case 2: 무수히 많은 해 — 직선 2개가 겹침 (실질적으로 같은 식)
  Case 3: 해 없음 — 직선 2개가 평행 (모순)

  2D 시각화:
  
  Case 1:        Case 2:        Case 3:
    ╲  ╱           ──────         ──────
     ╲╱            ──────         ──────
     ╱╲                          (평행, 안 만남)
    ╱  ╲
  한 점에서 만남    완전히 겹침

이것을 판별하는 도구가 행렬식(determinant)과 랭크(rank)이다.
```

## 5. 행렬식 (Determinant) — 변환이 공간을 얼마나 늘이거나 줄이는가

### 5.1 행렬식의 기하학적 의미 — 왜 이것이 중요한가

```
🔴 [핵심 통찰]
  det(A) = "선형 변환 A가 넓이(또는 부피)를 몇 배로 바꾸는가"

  det(A) = 2   →  넓이가 2배로 늘어남
  det(A) = 0.5 →  넓이가 절반으로 줄어듦
  det(A) = -1  →  넓이는 같지만 방향이 뒤집힘 (거울 반사)
  det(A) = 0   →  차원이 찌그러짐! (2D가 1D 선으로, 3D가 2D 면으로)

왜 det(A) = 0이면 역행렬이 없는가:
  A가 공간을 찌그러뜨려서 차원을 줄였다면,
  정보가 소실된 것이므로 되돌릴 수(역변환할 수) 없다.
  
  비유: 종이를 구기면 평면 정보가 사라져서 원래 모양을 복원할 수 없다.
```

### 5.2 2×2 행렬식 — 왜 ad - bc인가

```
🟢 [유도 가능]

  A = [ a  b ]
      [ c  d ]

  A의 두 열벡터: (a, c)와 (b, d)
  이 두 벡터가 이루는 평행사변형의 넓이 = det(A) = ad - bc

  왜 ad - bc인가:

  평행사변형을 좌표계에 그려보면:
  
       (a+b, c+d)
      ╱        ╱
  (b,d)      (a,c)
      ╲      ╱
       (0,0)

  전체 직사각형 넓이에서 삼각형들을 빼면:
  넓이 = ad - bc (부호는 방향 정보를 담음)

  더 직관적으로:
  a와 d는 "대각선 방향" → 넓이를 키우는 방향
  b와 c는 "반대각선 방향" → 넓이를 줄이는 방향 (기울어짐)
  → 넓이 = (키우는 방향) - (줄이는 방향) = ad - bc
```

### 5.3 행렬식의 성질 — 외워야 하나?

```
🟢 [유도 가능] 기하학적 의미에서 자연스럽게 따라 나온다:

  det(AB) = det(A) · det(B)
    왜: A가 넓이를 a배, B가 b배로 바꾸면, 합성은 ab배.

  det(Aᵀ) = det(A)
    왜: 전치해도 평행사변형의 넓이는 같다.

  det(A⁻¹) = 1/det(A)
    왜: A가 넓이를 a배로 바꾸면, 역변환은 1/a배로 되돌린다.

  행 하나에 c를 곱하면 det가 c배
    왜: 한 변의 길이를 c배 하면 넓이도 c배.

  두 행을 교환하면 det의 부호 반전
    왜: 방향(orientation)이 뒤집힌다.
```

## 6. 선형독립, 기저, 차원 — 공간의 "뼈대"

### 6.1 일차결합 — 벡터를 섞는 법

```
🔴 [정의] 벡터 v₁, v₂, ..., vₖ의 일차결합(linear combination):
  c₁v₁ + c₂v₂ + ... + cₖvₖ    (c₁, ..., cₖ는 스칼라)

이것이 중요한 이유:
  선형 변환은 일차결합을 보존한다.
  따라서 일차결합으로 만들 수 있는 모든 벡터의 집합(= span)이
  그 벡터들이 "커버하는 공간"이 된다.

span{v₁, ..., vₖ} = {c₁v₁ + ... + cₖvₖ | 모든 스칼라 c₁,...,cₖ}
```

### 6.2 선형독립 — 중복 없는 벡터 세트

```
🔴 [정의] v₁, ..., vₖ가 선형독립(linearly independent)이다 ⟺
  c₁v₁ + c₂v₂ + ... + cₖvₖ = 0 이 되려면
  c₁ = c₂ = ... = cₖ = 0이어야만 한다.

직관: "어떤 벡터도 나머지 벡터들의 일차결합으로 표현할 수 없다"
     = "각 벡터가 새로운 방향의 정보를 가져온다"
     = "중복이 없다"

반대: 선형종속(linearly dependent)이면
  한 벡터가 다른 벡터들로 표현 가능 → 그 벡터는 "쓸모없는 중복"

예시:
  v₁ = (1, 0), v₂ = (0, 1)         → 독립 (서로 다른 방향)
  v₁ = (1, 0), v₂ = (2, 0)         → 종속 (v₂ = 2v₁, 같은 방향)
  v₁ = (1, 0), v₂ = (0, 1), v₃ = (1, 1) → 종속 (v₃ = v₁ + v₂)

🔵 [CS 연결]
  데이터의 "특성(feature)"이 선형종속이면:
  → 중복 정보 → 모델이 불안정해짐 (다중공선성, multicollinearity)
  → 차원 축소(PCA)로 독립인 성분만 추출하는 것이 해결책
```

### 6.3 기저와 차원 — 공간을 기술하는 최소 도구

```
🔴 [정의]
  기저(basis) = 벡터 공간을 span하는 선형독립인 벡터 집합
  차원(dimension) = 기저 벡터의 개수

왜 이 개념이 중요한가:

  기저는 "좌표계를 정하는 것"이다.
  
  ℝ²의 표준 기저: {(1,0), (0,1)} → x축, y축
  다른 기저도 가능: {(1,1), (1,-1)} → 45° 회전된 축
  
  기저를 바꾸면 같은 벡터의 좌표(숫자)가 달라진다.
  벡터 자체(화살표)는 변하지 않지만, 표현이 달라진다.
  
  비유: 같은 위치를 "서울 기준 동쪽 50km"라고도,
       "수원 기준 북동쪽 20km"라고도 표현할 수 있다.
       위치는 같지만 기준(기저)에 따라 좌표가 다르다.

🟢 [유도 가능]
  ℝⁿ의 차원은 n이다.
  왜: n개의 선형독립 벡터가 필요하고 충분하다.
  n개보다 많으면 반드시 종속이 된다 (ℝⁿ에 n+1개의 독립 벡터는 불가).

🔵 [CS 연결]
  "차원의 저주": 차원이 높을수록 데이터가 희소해짐
  → 1000차원 공간에서 데이터 100개 = 거의 모든 곳이 빈 공간
  → PCA로 차원 축소: "실제로 의미 있는 차원"만 추출
```

### 6.4 랭크 — 행렬이 실제로 사용하는 차원

```
🔴 [정의] rank(A) = A의 열들 중 선형독립인 것의 최대 개수
                   = A의 행들 중 선형독립인 것의 최대 개수 (같다!)

직관: 
  rank = "이 행렬(변환)이 실제로 활용하는 차원의 수"

  m×n 행렬 A의 rank가 r이면:
    n차원 입력 공간 → A를 통과하면 → r차원 출력 공간 (찌그러짐 가능)

  rank = n (full column rank): 열들이 모두 독립 → 정보 손실 없음
  rank < n: 일부 방향의 정보가 소실됨 → 역변환 불가

🟢 [유도 가능] rank-nullity 정리:
  rank(A) + nullity(A) = n  (열의 수)
  
  nullity = "A에 의해 0으로 보내지는 벡터들의 차원" (= 커널의 차원)
  
  왜: n차원 입력이 rank만큼 살아남고, 나머지(nullity)는 0으로 찌그러짐.
  살아남는 것 + 사라지는 것 = 전체
```

## 7. 역행렬 — 변환을 되돌리기

### 7.1 역행렬이란 — 왜 필요한가

```
🔴 [정의] A⁻¹은 A의 효과를 정확히 되돌리는 행렬:
  A⁻¹A = AA⁻¹ = I  (단위행렬)

Ax = b의 해: x = A⁻¹b (양변에 A⁻¹를 곱함)

역행렬이 존재할 조건:
  det(A) ≠ 0 ⟺ rank(A) = n ⟺ A의 열들이 선형독립

  왜 det(A) = 0이면 역행렬이 없는가: (§5.1에서 설명)
  det = 0이면 공간을 찌그러뜨림 → 정보 소실 → 되돌리기 불가
```

### 7.2 2×2 역행렬 — 왜 이 형태인가

```
🟢 [유도 가능]

  A = [ a  b ]    A⁻¹ = (1/det(A)) · [  d  -b ]
      [ c  d ]                        [ -c   a ]

  det(A) = ad - bc

  왜 이런 형태인가:
  A⁻¹A = I를 만족하는 행렬을 연립방정식으로 풀면 이 결과가 나온다.
  
  패턴:
  - 주대각선(a,d)이 서로 교환됨
  - 부대각선(b,c)의 부호가 반전됨
  - 전체를 det(A)로 나눔

  det(A)가 작을수록 A⁻¹의 원소가 커짐 → 수치적으로 불안정
  det(A) = 0이면 나눌 수 없음 → 역행렬 존재하지 않음

🔵 [CS 연결]
  실무에서 역행렬을 직접 구하는 경우는 드물다.
  O(n³) 비용이 들고 수치적으로 불안정하기 때문.
  대신 LU 분해, QR 분해, 반복법 등을 사용한다.
```

## 8. 고유값과 고유벡터 — 변환의 "본질적 방향"

### 8.1 고유값/고유벡터란 — 왜 이것이 존재하는가

```
🔴 [정의]
  Av = λv 를 만족하는 0이 아닌 벡터 v와 스칼라 λ
  
  v = 고유벡터 (eigenvector, "고유한 벡터")
  λ = 고유값 (eigenvalue, "고유한 값")

읽는 법: "A에 v를 곱하면, v 방향은 변하지 않고 크기만 λ배 된다"
```

**왜 이것이 존재하고, 왜 중요한가:**

```
대부분의 벡터에 A를 곱하면 방향과 크기 모두 변한다.
그런데 특별한 방향이 있다: A를 곱해도 방향이 변하지 않는 방향.
그 방향의 벡터가 고유벡터이고, 크기 변화 배수가 고유값이다.

시각화: A = [ 2  1 ] 의 효과
            [ 0  3 ]

  대부분의 벡터:  →  ↗  (방향도 크기도 변함)
  
  고유벡터 방향:  →  →→  (방향 유지, 크기만 변함!)
                  ↗  ↗↗↗

왜 중요한가:

  고유벡터 방향에서는 행렬이 단순한 "스칼라 곱"처럼 행동한다!
  Av = λv → A는 v 방향에서 그냥 λ를 곱하는 것과 같다.
  
  복잡한 행렬 연산이 → 단순한 숫자 곱셈으로 분해된다.
  이것이 고유값 분해의 핵심 아이디어이다.
```

### 8.2 고유값을 찾는 법 — 왜 det(A - λI) = 0인가

```
🟢 [유도 가능]

  Av = λv
  Av - λv = 0
  (A - λI)v = 0       ← λv = λIv이므로

  이 식이 v ≠ 0인 해를 가지려면:
  (A - λI)가 역행렬을 갖지 않아야 한다.
  (역행렬이 있으면 v = (A-λI)⁻¹ · 0 = 0뿐이니까)
  
  역행렬이 없을 조건: det(A - λI) = 0
  
  이것이 특성방정식(characteristic equation)이다.

예시: A = [ 2  1 ]
          [ 0  3 ]

  det(A - λI) = det[ 2-λ   1  ] = (2-λ)(3-λ) - 0 = 0
                    [  0   3-λ ]
  
  → λ = 2 또는 λ = 3

  λ = 2일 때: (A - 2I)v = 0 → [ 0  1 ] v = 0 → v = c(1, 0)
                                [ 0  1 ]
  
  λ = 3일 때: (A - 3I)v = 0 → [ -1  1 ] v = 0 → v = c(1, 1)
                                [  0  0 ]
```

### 8.3 대각화 — 왜 이것이 유용한가

```
🟢 [유도 가능] n×n 행렬 A가 n개의 선형독립 고유벡터를 가지면:

  A = PDP⁻¹

  P = [v₁ | v₂ | ... | vₙ]   (고유벡터들을 열로 나열)
  D = diag(λ₁, λ₂, ..., λₙ)  (고유값들을 대각선에 배치)

왜 이 분해가 성립하는가:
  AP = A[v₁|...|vₙ] = [Av₁|...|Avₙ] = [λ₁v₁|...|λₙvₙ] = PD
  따라서 A = PDP⁻¹

왜 유용한가:

  A^k = PD^kP⁻¹
  
  D^k = diag(λ₁^k, ..., λₙ^k)  ← 대각행렬의 거듭제곱은 쉽다!

  행렬의 거듭제곱: O(n³ · k) → O(n³)  (k에 무관!)

🔵 [CS 연결]
  PageRank: 거대 행렬의 거듭제곱이 수렴하는 벡터 = 주요 고유벡터
    웹의 "중요한 페이지" = 링크 행렬의 고유벡터
  
  마르코프 체인: 전이 행렬의 거듭제곱 → 정상 분포 = 고유값 1의 고유벡터
  
  PCA (§10에서 상세): 공분산 행렬의 고유벡터 = 데이터의 주요 방향
```

## 9. 직교성과 정규직교 기저 — "깔끔한 좌표계"

### 9.1 직교란 — 왜 수직이 좋은가

```
두 벡터가 직교(orthogonal): u · v = 0  (내적이 0, 즉 수직)

왜 직교가 좋은가:
  직교하는 벡터들은 서로 완전히 독립적인 정보를 담는다.
  한 축의 변화가 다른 축에 전혀 영향을 주지 않는다.

  비유: 동서 방향 이동과 남북 방향 이동은 독립적이다.
       동쪽으로 아무리 가도 남북 위치는 변하지 않는다.
       → 직교 좌표계가 자연스러운 이유

정규직교(orthonormal) 기저:
  서로 직교 + 각 벡터의 크기가 1
  
  왜 크기 1로 맞추는가:
  단위 벡터로 정규화하면 좌표 계산이 간단해진다.
  v = c₁e₁ + c₂e₂에서 cᵢ = v · eᵢ  (그냥 내적하면 됨!)
  
  정규직교가 아니면 연립방정식을 풀어야 좌표를 구할 수 있다.
  정규직교이면 내적 한 번이면 끝이다.
```

### 9.2 그람-슈미트 과정 — 직교 기저를 만드는 방법

```
🟢 [유도 가능] 아이디어:
  "비직교 벡터에서 이미 처리한 방향의 성분을 빼면, 나머지는 수직"

  v₁, v₂가 주어졌을 때:
  
  u₁ = v₁                          (첫 벡터는 그대로)
  u₂ = v₂ - proj(v₂ onto u₁)      (v₂에서 u₁ 방향 성분을 제거)
     = v₂ - [(v₂·u₁)/(u₁·u₁)] · u₁

  시각화:
  
        v₂
       ╱│
      ╱ │ u₂ (v₂에서 u₁ 방향을 뺀 나머지 = u₁에 수직)
     ╱  │
    ╱   │
   ────●────── u₁ (= v₁)
      proj

왜 작동하는가:
  투영(projection)은 "한 방향의 성분만 추출"하는 것이다.
  원래 벡터에서 투영을 빼면, 그 방향의 성분이 0이 된다 = 수직.

🔵 [CS 연결]
  QR 분해: A = QR (Q: 직교행렬, R: 상삼각행렬)
  → 그람-슈미트로 Q를 만들고, R은 자동으로 결정됨
  → 수치적으로 안정한 연립방정식 풀이의 기반
```

## 10. 특이값 분해 (SVD) — 선형대수의 "만능 도구"

### 10.1 SVD란 — 왜 이것이 최고인가

```
🔴 [정의]
  임의의 m×n 행렬 A는 다음과 같이 분해된다:
  
  A = UΣVᵀ

  U: m×m 직교행렬 — 출력 공간의 직교 기저
  Σ: m×n 대각행렬 — 특이값(σ₁ ≥ σ₂ ≥ ... ≥ 0)이 대각선에
  V: n×n 직교행렬 — 입력 공간의 직교 기저

왜 이것이 대각화보다 강력한가:
  대각화 A = PDP⁻¹은 정사각 행렬이고 고유벡터가 n개일 때만 가능
  SVD는 어떤 행렬이든 (직사각이든, 정사각이든) 항상 가능!
```

**SVD가 하는 일을 기하학적으로 이해하기:**

```
  행렬 A에 의한 변환 = 세 단계로 분해:

  Step 1: Vᵀ — 입력 공간에서 회전/반사
  Step 2: Σ  — 각 축을 σᵢ만큼 늘이거나 줄임
  Step 3: U  — 출력 공간에서 회전/반사

  입력 원 → Vᵀ → 회전된 원 → Σ → 타원 → U → 회전된 타원

  어떤 선형 변환이든 "회전 → 늘림 → 회전"으로 분해된다!
  이것이 SVD의 기하학적 의미이다.

  σ의 크기 = 각 방향으로 얼마나 늘어나는가
  σ가 큰 방향 = 데이터의 주요 변동 방향
  σ가 작은 방향 = 노이즈나 중요하지 않은 방향
```

### 10.2 저랭크 근사 — 왜 SVD로 압축할 수 있는가

```
🟢 [유도 가능] Eckart-Young 정리:

  A ≈ σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + ... + σᵣuᵣvᵣᵀ
  
  상위 k개의 특이값만 사용하면:
  A_k = σ₁u₁v₁ᵀ + ... + σₖuₖvₖᵀ
  
  이것이 "rank-k 행렬 중 A에 가장 가까운 것"이다!

왜 작동하는가:
  σ₁ ≥ σ₂ ≥ ... 이므로, 앞의 특이값이 가장 중요한 정보.
  뒤의 작은 특이값들은 노이즈에 가까움.
  → 큰 것만 남기고 버려도 핵심 정보는 보존됨.

수치 예시:
  1000×1000 행렬 (100만 개 숫자)
  상위 50개 특이값만 사용하면:
  저장: 50×(1000+1000+1) ≈ 10만 개 숫자 → 10배 압축!
  
🔵 [CS 연결]
  이미지 압축: 이미지 = 행렬, SVD로 상위 k개만 보존
  추천 시스템: 사용자×아이템 평점 행렬 → SVD로 잠재 요인 추출
  LSA (잠재 의미 분석): 단어×문서 행렬 → SVD로 의미 차원 추출
  노이즈 제거: 작은 특이값 = 노이즈 → 제거하면 신호 개선
```

## 11. 주성분 분석 (PCA) — 데이터의 본질적 방향 찾기

### 11.1 PCA란 — 왜 필요한가

```
문제: 100차원 데이터가 있다. 시각화하려면 2~3차원으로 줄여야 한다.
     어떤 방향으로 "잘라내야" 정보 손실이 최소인가?

답: 데이터의 분산(variation)이 가장 큰 방향을 찾는다.
    분산이 큰 방향 = 데이터가 가장 많이 퍼져 있는 방향 = 정보가 많은 방향
```

**PCA의 원리 — 고유값분해와 SVD의 조합:**

```
🟢 [유도 가능]

Step 1: 데이터의 공분산 행렬(covariance matrix) C를 구한다.
  C = (1/n) · XᵀX   (X: 중심화된 데이터 행렬)
  
  C의 (i,j) 원소 = "i번째 특성과 j번째 특성이 함께 변하는 정도"
  C는 대칭 행렬 → 고유값이 모두 실수, 고유벡터가 직교

Step 2: C의 고유값 분해를 구한다.
  C = VΛVᵀ
  
  고유벡터 v₁, v₂, ...: 데이터의 "주요 방향" (주성분)
  고유값 λ₁ ≥ λ₂ ≥ ...: 각 방향의 분산 크기

Step 3: 상위 k개 고유벡터를 선택하여 차원 축소.
  X_reduced = X · V_k   (n×d 데이터 → n×k 데이터)

왜 고유벡터가 "주요 방향"인가:
  공분산 행렬의 고유벡터 = 데이터 분산이 최대인 방향
  
  C의 고유벡터 v에 대해: vᵀCv = λ
  λ = v 방향으로 투영했을 때의 분산
  λ가 가장 큰 고유벡터 = 분산이 가장 큰 방향 = 제1주성분

🔵 [CS 연결]
  얼굴 인식: 얼굴 이미지의 PCA → "고유얼굴(eigenfaces)"
  자연어 처리: 단어 벡터의 PCA → 의미 공간 시각화
  이상 탐지: PCA 후 복원 오차가 큰 데이터 = 이상치
  전처리: 고차원 데이터의 노이즈 제거 + 학습 속도 향상
```

## 12. 선형대수의 핵심 정리 — 모든 것의 동치

n×n 행렬 A에 대해, 다음은 모두 동치이다 (하나가 참이면 전부 참):

```
┌────────────────────────────────────────────────────────────┐
│ 역행렬 A⁻¹이 존재한다                                       │
│ det(A) ≠ 0                                                 │
│ rank(A) = n                                                │
│ A의 열벡터들이 선형독립이다                                   │
│ A의 행벡터들이 선형독립이다                                   │
│ Ax = 0의 해가 x = 0뿐이다 (자명한 해만 존재)                 │
│ Ax = b가 모든 b에 대해 유일한 해를 가진다                     │
│ A의 열벡터들이 ℝⁿ을 span한다                                │
│ A의 고유값 중 0이 없다                                       │
│ A의 특이값 중 0이 없다                                       │
│ Aᵀ A가 양정치(positive definite)이다                        │
└────────────────────────────────────────────────────────────┘

이 동치들이 왜 성립하는가:
  모두 "A가 정보를 잃지 않는다(공간을 찌그러뜨리지 않는다)"의 
  서로 다른 표현이다.

  det(A) ≠ 0 → 넓이가 0으로 안 줄어듦 → 찌그러지지 않음
  rank = n → 모든 방향 보존 → 찌그러지지 않음  
  역행렬 존재 → 되돌릴 수 있음 → 정보 손실 없음
  고유값 중 0 없음 → 어떤 방향도 완전히 사라지지 않음
  
  전부 같은 말을 다른 각도에서 한 것이다.
```

## 14. 정리 — 선형대수를 관통하는 원리

```
[원리 1] 선형성: T(au + bv) = aT(u) + bT(v)
  → 부분을 알면 전체를 안다. 이것이 모든 것의 출발점.

[원리 2] 행렬 = 선형 변환의 기록
  → 행렬의 열 = 단위벡터가 어디로 가는지

[원리 3] 선형독립 = 중복 없음
  → 기저 = 최소한의 비중복 벡터 → 차원 = 기저의 개수

[원리 4] 행렬식 = 넓이/부피 변화율
  → det = 0이면 찌그러짐 = 정보 손실 = 역행렬 없음

[원리 5] 고유값 = 변환의 본질적 행동
  → 고유벡터 방향에서 행렬은 단순한 숫자 곱셈

[원리 6] 직교 = 독립 + 깔끔
  → 직교 기저에서 좌표 계산 = 내적 한 번

[원리 7] SVD = 모든 행렬의 궁극적 분해
  → 회전 × 늘림 × 회전. 항상 가능.

외워야 할 것:
  🔴 내적 공식, 행렬 곱의 정의
  🔴 det(2×2) = ad - bc
  🔴 Av = λv (고유값 정의)
  🔴 A = UΣVᵀ (SVD 정의)

나머지는 원리에서 유도하거나 의미를 이해하면 재구성할 수 있다.
```
