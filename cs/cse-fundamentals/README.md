# CSE Fundamentals — 컴퓨터 과학 기초 종합 교과서

> **"컴퓨터 과학은 컴퓨터에 관한 학문이 아니다. 마치 천문학이 망원경에 관한 학문이 아닌 것처럼."**
> — Edsger W. Dijkstra

## 이 교과서에 대하여

이 저장소는 컴퓨터 과학 및 공학(CSE)의 기초 이론을 **21개 챕터**로 체계화한 디지털 교과서입니다. 각 챕터는 독립적인 README.md 파일로 구성되어 있으며, 단순한 키워드 나열이 아닌 **개념의 직관적 설명, 수학적 정의, 공식, 시각화 도표, 그리고 분야 간 연결 관계**까지 포함합니다.

### 대상 독자

- CS 전공자로서 전체 기초를 한 번 정리하고 싶은 학부생/대학원생
- 기술 면접(코딩 인터뷰, 시스템 디자인)을 준비하는 엔지니어
- 논문을 읽기 위한 배경 지식을 쌓고자 하는 연구 입문자
- 특정 과목의 핵심 개념을 빠르게 복습하고 싶은 실무자

### 이 교과서의 철학

1. **원리 중심 서술**: 공식을 나열하지 않습니다. "왜 이렇게 생겼는가", "어떤 원리들이 조합되어 이 결과가 나오는가"를 중심으로 설명합니다.
2. **🔴🟢🔵 분류 체계**: 모든 내용을 세 가지로 분류합니다.
   - 🔴 **[자연/정의]** — 자연현상이거나 약속. 외워야 한다.
   - 🟢 **[유도 가능]** — 원리를 조합하면 따라 나온다. 외울 필요 없다.
   - 🔵 **[연결]** — 이 원리가 CS의 어디에서 왜 쓰이는지.
3. **기호 읽기 가이드**: 각 챕터 §0.5에 해당 분야의 기호와 읽는 법을 수록합니다. ε(엡실론), ∇(나블라), Σ(시그마) 등을 처음 보는 독자도 읽을 수 있습니다.
4. **연결성**: 분야 간의 관계를 명시합니다. 선형대수가 왜 머신러닝에 필수인지, 정수론이 왜 암호학의 기반인지 — 이런 연결고리를 놓치지 않습니다.
5. **시각적 표현**: ASCII 다이어그램, 비교 표, 단계별 유도를 사용하여 텍스트만으로도 구조를 파악할 수 있게 합니다.
6. **실용성**: 이론이 실제 시스템, 알고리즘, 소프트웨어에서 어떻게 쓰이는지를 항상 함께 다룹니다.

## 각 챕터의 구성 방식

모든 챕터 README는 다음과 같은 일관된 구조를 따릅니다:

```
# Ch.XX — 챕터 제목

## 0. 이 챕터를 읽기 전에
   - 선수 지식 안내
   - 이 분야가 CS에서 왜 중요한지 (동기 부여)

## 1~N. 본문 섹션
   - 개념 정의 (직관적 설명 → 형식적 정의)
   - 수식과 공식 (코드 블록 내 수학 표기)
   - 시각화 도표 (ASCII 다이어그램, 비교 표)
   - 예제와 풀이
   - CS 실무에서의 활용 사례

## N+1. 분야 간 연결
   - 다른 챕터와의 관계
   - 이 분야의 지식이 어디에 쓰이는지

## N+2. 더 깊이 공부하기 위한 자료
   - 추천 교과서
   - 추천 온라인 강의
   - 관련 논문/학회
```

## 수학 표기 규약

이 교과서에서는 Markdown 환경의 한계를 고려하여, 수학 공식을 **코드 블록** 안에 작성합니다. 다음과 같은 표기 규약을 사용합니다:

```
기본 표기:
  x^n         → xⁿ (거듭제곱)
  x_i         → xᵢ (아래첨자)
  sqrt(x)     → √x (제곱근)
  sum_{i=1}^{n} → Σ (시그마, 합)
  prod_{i=1}^{n} → Π (파이, 곱)
  integral_a^b → ∫[a,b] (적분)
  partial f / partial x → ∂f/∂x (편미분)
  lim_{x->a}  → lim(x→a) (극한)
  infinity    → ∞ (무한)

집합 표기:
  A ∪ B       → 합집합
  A ∩ B       → 교집합
  A ⊂ B       → 부분집합
  ∅            → 공집합
  ∈            → 원소
  |A|          → 집합의 크기(기수)
  ℝ, ℤ, ℕ, ℚ, ℂ → 실수, 정수, 자연수, 유리수, 복소수 집합

논리 표기:
  ∀            → 모든 (전칭 기호)
  ∃            → 존재한다 (존재 기호)
  ∧            → AND
  ∨            → OR
  ¬            → NOT
  →            → 조건 (if ... then)
  ↔            → 쌍조건 (if and only if)
  ⊢            → 증명 가능 (derives)
  ⊨            → 모델이 만족 (entails)

행렬/벡터:
  [a, b; c, d] → 2×2 행렬 (세미콜론으로 행 구분)
  <v, w>       → 내적 (inner product)
  ||v||        → 노름 (norm)
  A^T          → 전치 행렬
  A^{-1}       → 역행렬

확률:
  P(A)         → 사건 A의 확률
  P(A|B)       → B가 주어졌을 때 A의 조건부 확률
  E[X]         → 기댓값
  Var(X)       → 분산
  Cov(X,Y)     → 공분산
  N(μ, σ²)     → 정규분포

복잡도:
  O(f(n))      → Big-O (상한)
  Ω(f(n))      → Big-Omega (하한)
  Θ(f(n))      → Big-Theta (타이트 바운드)
  o(f(n))      → Little-o (엄격한 상한)
```
