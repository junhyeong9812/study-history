## 1. 출발점: "변화"를 어떻게 수학으로 다룰 것인가

### 1.1 미적분이 태어난 이유

물체가 움직인다. "지금 이 순간 얼마나 빠른가?"라는 질문에 답하려면 어떻게 해야 할까.

```
평균 속도는 쉽다:
  평균 속도 = (이동 거리) / (걸린 시간) = Δs / Δt

그런데 "순간 속도"란?
  Δt를 0으로 보내면? → 0/0이 된다.
  
  이 "0/0 문제"를 해결하기 위해 극한(limit)이라는 도구가 만들어졌고,
  극한으로 정의된 순간 변화율이 미분(derivative)이고,
  변화율을 거꾸로 누적한 것이 적분(integral)이다.
```

즉, 미적분의 전체 체계는 **하나의 질문**에서 출발한다: **"순간적인 변화를 어떻게 정확히 기술할 것인가?"**

## 2. 극한 (Limit) — 미적분의 언어

### 2.1 극한이 필요한 이유

🔴 **[자연/정의]** 실수는 연속적이다. 두 실수 사이에는 항상 또 다른 실수가 있다. 이것은 실수체계의 성질(완비성)이며, 우리가 받아들여야 하는 출발점이다.

이 연속성 때문에 "한없이 가까이 간다"는 개념을 정밀하게 다룰 수 있다. 극한은 바로 이 "한없이 가까이"를 수학적으로 정의한 것이다.

### 2.2 극한의 정의 — 왜 이렇게 복잡한가

```
lim(x→a) f(x) = L

🔴 [정의] ε-δ 정의:
  "임의의 ε > 0에 대해, δ > 0이 존재하여:
   0 < |x - a| < δ이면 |f(x) - L| < ε"
```

**왜 이렇게 생겼는가:**

이 정의는 **"한없이 가까이"라는 모호한 말을 없애기 위해** 만들어졌다. 구조를 뜯어보면:

```
"한없이 가까이 가면 함수값도 한없이 가까워진다"
  ↓ 수학적으로 번역
"아무리 까다로운 기준(ε)을 들이대도,
 x를 a 근처(δ 안)에 가져가면 기준을 통과한다"

이것은 "도전-응답" 게임이다:
  상대방: "f(x)가 L에서 0.001 이내에 들어오게 해봐" (ε = 0.001)
  나:     "x를 a에서 0.00005 이내로 가져가면 됩니다" (δ = 0.00005)
  상대방: "그럼 0.0000001 이내에는?" (ε = 0.0000001)
  나:     "x를 a에서 ... 이내로 가져가면 됩니다" (더 작은 δ)
  
  이 게임에서 내가 항상 이길 수 있으면 → 극한이 존재한다.
```

**왜 0 < |x - a|인가 (x ≠ a인 이유):**

극한은 "a에 도달했을 때"가 아니라 "a에 다가갈 때"의 행동을 본다. f(a) 자체는 정의되지 않아도 괜찮다. 이것이 극한의 핵심 아이디어이다.

### 2.3 극한의 성질들 — 외워야 하나?

🟢 **[유도 가능]** 극한의 사칙연산 성질은 ε-δ 정의로부터 증명된다. 외울 필요 없다. 직관적으로도 당연하다:

```
두 함수가 각각 L과 M에 가까워지고 있으면:
  - 더한 것은 L+M에 가까워진다
  - 곱한 것은 L·M에 가까워진다
  - 나눈 것은 L/M에 가까워진다 (M ≠ 0)

이것은 "가까이 가는 것"의 본질에서 자연스럽게 따라 나온다.
```

🔴 **[외워야 하는 특수 극한들]** — 이것들은 자연의 성질이거나, 증명이 비자명하여 결과를 기억해두는 것이 효율적이다:

```
(1) lim(x→0) sin(x)/x = 1

    왜 1인가: 단위원에서 기하학적으로 증명된다.
    호의 길이(x), 높이(sin x), 접선 길이(tan x) 사이에
    sin(x) ≤ x ≤ tan(x) (0 < x < π/2)
    양변을 sin(x)로 나누면:
    1 ≤ x/sin(x) ≤ 1/cos(x)
    x→0이면 1/cos(x)→1이므로, 샌드위치 정리에 의해 x/sin(x)→1
    
    이것은 "원의 기하학적 성질"에서 나온다. 외워야 한다.

(2) lim(x→∞) (1 + 1/x)^x = e ≈ 2.71828...

    왜 하필 이 값인가: 이것이 자연상수 e의 정의 중 하나이다.
    "연속 복리"를 무한히 자주 하면 도달하는 값이다.
    
    복리 n번: (1 + r/n)^n → n→∞이면 e^r
    
    e는 자연현상에서 나타나는 상수이다.
    방사능 붕괴, 세균 증식, 냉각 법칙 — 모두 e가 등장한다.
    🔴 e의 값은 외워야 한다. "왜 이 값인가"는 자연이 정한 것이다.
```

### 2.4 연속성 — 극한의 자연스러운 확장

```
🔴 [정의] f가 x = a에서 연속이다 ⟺ lim(x→a) f(x) = f(a)

왜 이렇게 정의하는가:
  "함수의 그래프를 펜을 떼지 않고 그릴 수 있다"를 수학적으로 말한 것이다.
  극한이 존재하고, 함수값이 정의되어 있고, 둘이 같다 — 이 세 가지가
  "끊어지지 않는다"의 정확한 의미이다.
```

🟢 **[유도 가능] 중간값 정리(IVT):**

```
연속함수가 [a,b]에서 f(a) < 0이고 f(b) > 0이면,
f(c) = 0인 c가 (a,b)에 반드시 존재한다.

왜 성립하는가:
  연속이라는 것은 "점프 없이 부드럽게 이어진다"는 뜻이다.
  음수에서 양수로 갈 때, 부드럽게 이어져 있으면
  반드시 0을 지나야 한다. 뛰어넘을 수 없다.

  f(x)
    + ┤         ●
      │       ╱
    0 ┤─ ─ ●─ ─ ─ ─ ─    ← 반드시 0을 지남
      │   ╱
    - ┤ ●
      ┼──┼──┼──┼───── x
         a  c  b

🔵 [CS 연결] 이것이 이분 탐색(bisection)의 이론적 근거이다.
  f(a)와 f(b)의 부호가 다르면 → 가운데를 확인 → 범위를 반으로 줄인다
  → O(log n) 탐색이 가능한 이유가 IVT이다.
```

## 3. 미분 (Derivative) — 순간 변화율

### 3.1 미분의 정의 — 왜 이 형태인가

```
🔴 [정의]
  f'(a) = lim(h→0) [f(a+h) - f(a)] / h
```

**이 정의가 이렇게 생긴 이유:**

```
Step 1: 평균 변화율을 먼저 생각한다

  두 점 (a, f(a))와 (a+h, f(a+h))를 잇는 직선의 기울기:
  
  평균 변화율 = [f(a+h) - f(a)] / h

  f(x)
     │         ● (a+h, f(a+h))
     │       ╱╱
     │     ╱╱    ← 할선 (secant line)
     │   ●╱
     │  (a, f(a))
     ┼──────────── x

Step 2: h를 0으로 보낸다 → 할선이 접선이 된다

  h가 줄어들면 두 번째 점이 첫 번째 점에 가까워지고,
  할선이 접선에 가까워진다.

  f(x)
     │      ╱  ← 접선 (tangent line)
     │    ●╱
     │   ╱╱
     │  ╱
     ┼──────── x

  이 극한값이 바로 접선의 기울기 = 순간 변화율 = 미분이다.

왜 이것이 "순간 속도"인가:
  위치가 s(t)일 때, 평균 속도 = [s(t+h) - s(t)] / h
  h → 0이면 순간 속도 s'(t)가 된다.
  
  "구간을 무한히 줄여서 한 점에서의 변화율을 포착한다"
  이것이 미분의 본질이다.
```

### 3.2 미분 공식들 — 어디까지 외우고, 어디서부터 유도하나

🔴 **[외워야 하는 기본 도함수들]** — 이것들은 각각의 함수가 가진 고유한 성질에서 나온다. 극한 계산을 매번 할 수 없으므로 결과를 기억한다:

```
(x^n)' = n·x^(n-1)

  왜 이 형태인가: 이항정리로 유도된다.
  (x+h)^n = x^n + n·x^(n-1)·h + (n(n-1)/2)·x^(n-2)·h² + ...
  [f(x+h) - f(x)]/h = n·x^(n-1) + (h를 포함하는 항들)
  h→0이면 n·x^(n-1)만 남는다.

  → n이 밖으로 내려오고, 지수가 1 줄어드는 것은
    이항정리의 첫째 항에서 자연스럽게 나온다.
    이항정리를 기억하면 유도 가능하지만, 결과를 외우는 게 효율적이다.
```

```
(e^x)' = e^x    ← 자기 자신이 도함수인 유일한 함수(상수배 제외)

  왜 이런 특별한 성질을 가지는가:
  e의 정의 자체가 이 성질을 갖도록 만들어진 것이다.
  
  "변화율이 현재값에 비례하는" 현상: dy/dt = y
  이 미분방정식의 해가 y = e^t이다.
  
  세균 증식: 현재 세균 수에 비례하여 늘어남 → e^t
  방사능 붕괴: 현재 원자 수에 비례하여 줄어듦 → e^(-t)
  복리 이자: 현재 금액에 비례하여 불어남 → e^(rt)
  
  🔴 이것은 자연현상의 근본 패턴이다. e^x의 미분이 자기 자신이라는
  사실은 외워야 한다. "왜"는 자연이 이런 패턴을 가지기 때문이다.
```

```
(sin x)' = cos x
(cos x)' = -sin x

  왜 이런 관계인가:
  sin과 cos는 원운동을 기술한다. 단위원 위의 점 (cos t, sin t)를 생각하면:
  
  위치: (cos t, sin t) — 원 위를 돈다
  속도: (-sin t, cos t) — 항상 위치에 수직 (원의 접선 방향)
  
  sin(수직 좌표)의 변화율은 cos(수평 좌표의 속도 성분)이다.
  cos(수평 좌표)의 변화율은 -sin(수직 좌표의 속도 성분, 방향 반대)이다.
  
  이것은 원운동의 기하학에서 나온다.
  🔴 결과는 외워야 한다. 원리는 원운동의 기하학이다.
```

```
(ln x)' = 1/x

  왜 이 형태인가:
  ln은 e^x의 역함수이다.
  y = ln x  ⟺  e^y = x
  양변을 x에 대해 미분: e^y · (dy/dx) = 1
  dy/dx = 1/e^y = 1/x
  
  🟢 e^x의 미분을 알면 유도 가능하다.
```

### 3.3 미분 법칙들 — 왜 이렇게 생겼는가

🟢 **[모두 유도 가능]** — 미분의 정의 + 극한의 성질로부터 따라 나온다.

**곱의 법칙 (Product Rule):**

```
(f·g)' = f'·g + f·g'

왜 이 형태인가 — 직관적으로:

  직사각형의 넓이 = f × g라고 생각하자.
  f와 g가 동시에 조금씩 변하면:

  ┌──────────┬───┐
  │          │ Δg│
  │  f × g   │   │  ← 새 넓이 = (f+Δf)(g+Δg)
  │          │   │            = fg + f·Δg + g·Δf + Δf·Δg
  ├──────────┼───┤
  │  Δf × g  │   │  변화량 = f·Δg + g·Δf + Δf·Δg
  └──────────┴───┘            ↑       ↑        ↑
       f         Δf        f 고정    g 고정   무시 가능
                            g 변화   f 변화   (무한소의 곱)

  Δf·Δg 항은 Δf와 Δg가 모두 0으로 갈 때 훨씬 빨리 0에 접근하므로
  극한에서 사라진다. 따라서:
  
  d(fg)/dx = f·(dg/dx) + g·(df/dx) = f·g' + g·f'

  → 두 인수가 번갈아 미분되면서 나머지는 그대로 유지되는 구조.
```

**연쇄 법칙 (Chain Rule):**

```
[f(g(x))]' = f'(g(x)) · g'(x)

왜 이 형태인가:

  합성 함수 y = f(g(x))에서:
  x가 Δx만큼 변하면 → g(x)는 Δg만큼 변하고 → f는 Δf만큼 변한다.

  x ──(g)──→ u = g(x) ──(f)──→ y = f(u)
  Δx         Δu = g'(x)·Δx     Δy = f'(u)·Δu

  Δy/Δx = (Δy/Δu) · (Δu/Δx)
  
  극한을 취하면:
  dy/dx = (dy/du) · (du/dx) = f'(g(x)) · g'(x)

  → "변화율은 체인처럼 곱해진다"
  → 중간 단계를 거칠 때마다 각 단계의 변화율을 곱하면 된다.

🔵 [CS 연결] 이것이 딥러닝 역전파의 전부이다.
  
  신경망: x → z₁ = w₁x → a₁ = σ(z₁) → z₂ = w₂a₁ → L
  
  ∂L/∂w₁ = (∂L/∂z₂) · (∂z₂/∂a₁) · (∂a₁/∂z₁) · (∂z₁/∂w₁)
  
  각 층의 변화율을 체인처럼 곱한다. 이것이 연쇄 법칙이다.
  역전파라는 이름이 붙은 이유는 이 곱셈을 출력→입력 방향으로 하기 때문이다.
```

**몫의 법칙:**

```
(f/g)' = (f'g - fg') / g²

🟢 이것은 곱의 법칙 + 연쇄 법칙으로 유도된다:
   f/g = f · g^(-1)
   곱의 법칙: (f · g^(-1))' = f' · g^(-1) + f · (g^(-1))'
   연쇄 법칙: (g^(-1))' = -g^(-2) · g' = -g'/g²
   합치면: f'/g + f·(-g'/g²) = f'/g - fg'/g² = (f'g - fg')/g²

   → 외울 필요 없다. 곱의 법칙과 연쇄 법칙을 조합하면 나온다.
```

### 3.4 고계 미분 — 변화의 변화

```
f'(x): 1차 도함수 → "변화율" (속도)
f''(x): 2차 도함수 → "변화율의 변화율" (가속도)

물리적 직관:
  위치 s(t) → 속도 v(t) = s'(t) → 가속도 a(t) = v'(t) = s''(t)

f''의 기하학적 의미 — 곡률의 방향:
  f'' > 0: 그래프가 아래로 볼록 (∪ 모양) — 기울기가 증가 중
  f'' < 0: 그래프가 위로 볼록 (∩ 모양) — 기울기가 감소 중
  
  왜 이런가:
  f'' > 0이라는 것은 f'이 증가한다는 뜻이다.
  기울기(f')가 점점 커진다 → 그래프가 점점 가파르게 올라간다 → ∪ 모양
```

### 3.5 테일러 급수 — 왜 이 형태인가

```
핵심 아이디어:
  "복잡한 함수를 다항식으로 근사하고 싶다."
  다항식은 계산이 쉽기 때문이다.

  f(x)를 x = a 근처에서 다항식 P(x)로 근사한다면,
  P(a) = f(a)이고, P'(a) = f'(a)이고, P''(a) = f''(a)이고, ...
  모든 차수의 도함수가 일치하도록 만들고 싶다.

  P(x) = c₀ + c₁(x-a) + c₂(x-a)² + c₃(x-a)³ + ...

  P(a) = c₀ = f(a)                    → c₀ = f(a)
  P'(a) = c₁ = f'(a)                  → c₁ = f'(a)
  P''(a) = 2·c₂ = f''(a)              → c₂ = f''(a)/2!
  P'''(a) = 3·2·c₃ = f'''(a)          → c₃ = f'''(a)/3!

  패턴: c_n = f⁽ⁿ⁾(a) / n!

🟢 [유도 가능] 따라서:
  f(x) = Σ_{n=0}^{∞} f⁽ⁿ⁾(a)/n! · (x-a)ⁿ

  n!로 나누는 이유:
  (x-a)ⁿ을 n번 미분하면 n!이 나온다 (연쇄적으로 계수가 내려옴).
  이것을 상쇄하기 위해 n!로 나누는 것이다.
```

**주요 테일러 전개 — 외워야 하는가?**

```
🔴 [결과를 외우는 것이 효율적]

  e^x = 1 + x + x²/2! + x³/3! + ...

    원리: (e^x)⁽ⁿ⁾ = e^x이므로, x=0에서 모든 도함수가 1이다.
    따라서 계수는 1/n!이 된다.
    → e^x의 미분이 자기 자신이라는 성질 + 테일러 공식을 조합하면 유도 가능.
    → 그래도 결과를 외워두면 편하다.

  sin(x) = x - x³/3! + x⁵/5! - ...     (홀수 차수만)
  cos(x) = 1 - x²/2! + x⁴/4! - ...     (짝수 차수만)

    왜 이런 패턴인가:
    sin(0) = 0, sin'(0) = cos(0) = 1, sin''(0) = -sin(0) = 0, 
    sin'''(0) = -cos(0) = -1, sin⁽⁴⁾(0) = sin(0) = 0, ...
    
    0이 아닌 값이 홀수 차수에서만 나타나고, 부호가 교대한다.
    이것은 sin과 cos가 주기 4로 도함수가 순환하는 성질에서 나온다:
    sin → cos → -sin → -cos → sin → ...

🔵 [CS 연결]
  컴퓨터에서 sin(x) 계산: 하드웨어/라이브러리가 내부적으로
  범위 축소(range reduction) 후 다항식 근사(테일러 또는 체비셰프)를 사용한다.
  sin(x) ≈ x (|x|가 작을 때) — 이것은 1차 테일러 근사이다.
```

### 3.6 최적화 — 미분의 가장 중요한 응용

```
핵심 원리:

  "함수가 극값(최대/최소)을 가지려면 변화율이 0이어야 한다."

  왜? 극대점에서는 왼쪽에서 올라오다(f'>0) 오른쪽으로 내려간다(f'<0).
  연속적으로 변하는 f'이 양에서 음으로 바뀌려면 반드시 0을 지나야 한다.
  (→ IVT가 여기서도 쓰인다!)

  f'(c) = 0인 c를 임계점(critical point)이라 한다.

판정: 임계점이 극대인지 극소인지 어떻게 아는가?

  🟢 [유도 가능] 2차 도함수 판정법:
  f'(c) = 0일 때:
    f''(c) > 0 → 극소 (∪ 모양의 바닥)
    f''(c) < 0 → 극대 (∩ 모양의 꼭대기)

  왜:
    f''(c) > 0이면 f'이 c 근처에서 증가 중이다.
    f'(c) = 0이고 f'이 증가 중이면 → c 왼쪽에서 f' < 0, 오른쪽에서 f' > 0
    → c 왼쪽에서 감소, 오른쪽에서 증가 → 극소
```

## 4. 적분 (Integration) — 미분의 역과정, 그리고 누적

### 4.1 적분이란 무엇인가 — 두 가지 관점

적분에는 서로 다른 두 가지 출발점이 있다. 놀라운 것은 이 둘이 같다는 것이다.

```
관점 1: "미분의 역과정" (부정적분)
  F'(x) = f(x)인 F를 찾는 것.
  F를 f의 원시함수(antiderivative)라 한다.
  ∫ f(x) dx = F(x) + C

관점 2: "넓이의 축적" (정적분)
  곡선 y = f(x) 아래의 넓이를 구하는 것.
  구간 [a,b]를 아주 잘게 쪼개서 직사각형으로 근사한 후,
  조각 수를 무한히 늘린다.
  
  ∫[a,b] f(x) dx = lim(n→∞) Σ_{i=1}^{n} f(x_i*) · Δx

  f(x)
     │   ┌──┐
     │┌──┤  ├──┐
     ││  │  │  │┌──┐
     ││  │  │  ││  │     n개의 직사각형
     ┼┴──┴──┴──┴┴──┴── x
     a              b
     
     Δx = (b-a)/n → 0
     직사각형 넓이의 합 → 정확한 넓이
```

### 4.2 미적분학의 기본정리 — 왜 이것이 "기본"인가

```
🟢 [유도 가능 — 미적분의 핵심 정리]

  제2 기본정리: ∫[a,b] f(x) dx = F(b) - F(a)

  이 정리가 말하는 것:
  "넓이(적분) = 원시함수의 끝값 차이"

  관점 1(역미분)과 관점 2(넓이)가 같다는 것을 증명한다.
```

**왜 이것이 성립하는가 — 직관적 설명:**

```
  F(x) = ∫[a,x] f(t) dt 라고 정의하자.
  
  이것은 "a부터 x까지의 누적 넓이"이다.
  
  x가 조금 (Δx만큼) 증가하면, 넓이는 얼마나 늘어나는가?
  
  ΔF ≈ f(x) · Δx  (폭 Δx, 높이 ≈ f(x)인 얇은 직사각형)
  
  f(x)
     │
     │    ┌─┐
     │    │ │ ← f(x)·Δx (추가된 넓이)
     │    │ │
     │████│ │
     │████│ │
     ┼────┼─┼── x
     a    x x+Δx
  
  따라서 ΔF/Δx ≈ f(x), 극한을 취하면 F'(x) = f(x).
  
  → "넓이의 변화율 = 높이" — 너무나 당연하지 않은가!
  → 넓이를 한 조각씩 쌓아가는데, 각 조각의 높이가 f(x)이니까.
  
  F'(x) = f(x)이므로 F는 f의 원시함수이다.
  ∫[a,b] f(x) dx = F(b) - F(a).

이것이 미적분의 기본정리가 위대한 이유:
  리만 합(무한 합)을 직접 계산하지 않고,
  원시함수만 찾으면 양 끝값의 차이로 적분을 구할 수 있다.
  무한한 과정을 유한한 계산으로 바꿔준다.
```

### 4.3 적분 기법들 — 왜 이런 기법이 필요한가

모든 함수에 대해 원시함수를 쉽게 찾을 수 있는 것은 아니다. 적분 기법은 "어려운 적분을 쉬운 적분으로 변환하는 전략"이다.

**치환적분 — 연쇄 법칙의 역과정:**

```
🟢 [유도 가능] 연쇄 법칙: d/dx[F(g(x))] = F'(g(x)) · g'(x) = f(g(x)) · g'(x)

  양변을 적분하면:
  ∫ f(g(x)) · g'(x) dx = F(g(x)) + C

  u = g(x)로 치환하면 du = g'(x) dx이므로:
  ∫ f(u) du = F(u) + C

  → 연쇄 법칙에서 미분할 때 곱해졌던 g'(x)를 적분할 때 "흡수"하는 것.

  예시: ∫ 2x · cos(x²) dx
    u = x², du = 2x dx
    = ∫ cos(u) du = sin(u) + C = sin(x²) + C
    
    왜 되는가: cos(x²)을 미분한 것은 -sin(x²)·2x이다.
    거꾸로, 2x·cos(x²)의 원시함수는 sin(x²)이다.
    치환은 이 "역과정"을 체계적으로 하는 방법일 뿐이다.
```

**부분적분 — 곱의 법칙의 역과정:**

```
🟢 [유도 가능] 곱의 법칙: (uv)' = u'v + uv'

  양변을 적분하면:
  uv = ∫ u'v dx + ∫ uv' dx
  
  정리하면:
  ∫ uv' dx = uv - ∫ u'v dx

  또는: ∫ u dv = uv - ∫ v du

  → "어려운 적분을 더 쉬운 적분으로 바꾸는" 전략이다.
  → u를 미분하면 간단해지는 것, dv는 적분하기 쉬운 것을 고른다.

  예시: ∫ x · e^x dx
    u = x → du = dx    (미분하면 간단해짐)
    dv = e^x dx → v = e^x  (적분하기 쉬움)
    
    = x·e^x - ∫ e^x dx = x·e^x - e^x + C = e^x(x-1) + C
```

### 4.4 이상적분 — 무한을 다루는 방법

```
구간이 무한하거나 함수가 발산하는 경우:

  ∫[1,∞] 1/x² dx = lim(b→∞) [-1/x]₁ᵇ = lim(b→∞) (-1/b + 1) = 1

  ∫[1,∞] 1/x dx = lim(b→∞) [ln x]₁ᵇ = lim(b→∞) ln(b) = ∞

🔴 [외워야 하는 판정 기준] p-판정법:
  ∫[1,∞] 1/x^p dx:  p > 1이면 수렴,  p ≤ 1이면 발산

  왜 p = 1이 경계인가:
  1/x의 원시함수는 ln(x) → ∞로 발산 (로그 성장)
  1/x²의 원시함수는 -1/x → 0으로 수렴
  
  정확히 p = 1에서 "로그 성장 vs 수렴"의 경계가 생긴다.
  이것은 x^(-p)의 감소 속도와 관련된 자연현상이다.
  p > 1이면 충분히 빨리 감소하여 무한 합이 유한하다.

🔵 [CS 연결]
  조화급수 H_n = 1 + 1/2 + 1/3 + ... + 1/n ≈ ln(n)
  → 해시 테이블의 기대 탐색 길이, 쿠폰 수집 문제에 등장
  → "발산하지만 매우 느리게"라는 성질이 중요하다
```

## 5. 급수 — 무한 합을 다루는 도구

### 5.1 급수가 왜 필요한가

```
급수 = 무한히 많은 수를 더한 것: Σ_{n=1}^{∞} a_n

왜 필요한가:
  1. 테일러 급수가 급수이다 → 함수를 다항식 무한 합으로 표현
  2. 알고리즘 분석에서 반복 횟수의 합을 구해야 한다
  3. 확률에서 기댓값이 무한 합인 경우가 많다
  
핵심 질문: "무한히 더했는데 유한한 값이 될 수 있는가?" → 수렴/발산 문제
```

### 5.2 수렴 판정 — 왜 이런 판정법이 존재하는가

```
🔴 [기본 원리] 급수 Σ a_n이 수렴하려면 a_n → 0이어야 한다.

  왜? a_n이 0으로 가지 않으면, 계속 유의미한 양을 더하므로 합이 발산한다.
  주의: 역은 성립 안 한다! a_n → 0이어도 발산할 수 있다 (예: 조화급수).

🔴 [외워야 하는 기본 급수]
  기하급수: Σ r^n = 1/(1-r)   (|r| < 1일 때)
  
  왜 1/(1-r)인가:
  S = 1 + r + r² + r³ + ...
  rS =     r + r² + r³ + ...
  S - rS = 1
  S(1-r) = 1
  S = 1/(1-r)
  
  → 기하급수의 합 공식은 대수적으로 유도된다. 원리를 알면 외울 필요 없다.
  → 다만 결과가 워낙 자주 쓰이므로 외워두면 편하다.

  🔵 [CS 연결]
  1 + 2 + 4 + ... + 2^k = 2^(k+1) - 1 (기하급수, r=2)
  → 이진 트리의 총 노드 수
  → 동적 배열(ArrayList)의 amortized 복사 비용 분석
```

**수렴 판정법들의 핵심 아이디어:**

```
🟢 모든 판정법은 하나의 원리에서 나온다:
  "이미 수렴한다고 알려진 급수와 비교하여 판단한다"

비교 판정법:
  0 ≤ a_n ≤ b_n이고 Σb_n 수렴 → Σa_n도 수렴
  → "더 큰 것이 유한하면, 더 작은 것도 당연히 유한하다"

비율 판정법 (Ratio Test):
  L = lim |a_{n+1}/a_n|
  L < 1: 수렴,  L > 1: 발산
  
  왜 작동하는가:
  L < 1이면 각 항이 이전 항의 L배보다 작아진다 → 기하급수보다 빠르게 감소
  기하급수(|r|<1)가 수렴하므로, 이것도 수렴한다.
  
  → 본질적으로 "기하급수와의 비교"이다.
```

## 6. 다변수 미적분 — 고차원으로의 확장

### 6.1 왜 다변수가 필요한가

```
현실의 함수는 대부분 여러 변수에 의존한다:
  - 기온은 위도, 경도, 고도, 시간에 의존
  - 신경망의 손실은 수천~수십억 개의 가중치에 의존
  - 주가는 수많은 경제 지표에 의존

하나의 변수에 대한 미적분을 여러 변수로 자연스럽게 확장한 것이
다변수 미적분이다.
```

### 6.2 편미분 — 한 번에 하나씩

```
🔴 [정의] f(x₁, x₂, ..., x_n)의 x_i에 대한 편미분:

  ∂f/∂x_i = lim(h→0) [f(..., x_i+h, ...) - f(..., x_i, ...)] / h

왜 이렇게 하는가:
  다변수 함수에서 "모든 방향으로 동시에" 변화율을 구하는 것은 복잡하다.
  대신 "한 번에 하나의 변수만 바꾸고, 나머지는 고정"하는 전략을 쓴다.
  
  이것은 과학 실험의 "통제 변인" 개념과 같다:
  다른 조건을 모두 고정하고 하나만 바꿔본다.

  각 변수에 대해 이것을 반복하면 모든 방향의 정보를 얻을 수 있다.
```

### 6.3 그래디언트 — 편미분들의 조합

```
🟢 [유도 가능] 그래디언트는 모든 편미분을 벡터로 모은 것이다:

  ∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂x_n)

왜 이것이 "가장 가파른 방향"인가:

  방향 u로 Δ만큼 이동했을 때 f의 변화:
  Δf ≈ ∇f · u · Δ = |∇f| · |u| · cos(θ) · Δ
  
  |u| = 1(단위 벡터)이면:
  Δf ≈ |∇f| · cos(θ) · Δ
  
  cos(θ)가 최대(= 1)인 것은 θ = 0, 즉 u가 ∇f와 같은 방향일 때.
  → ∇f 방향이 f가 가장 빠르게 증가하는 방향이다.
  → -∇f 방향이 f가 가장 빠르게 감소하는 방향이다.
  
  이것은 내적의 성질(코사인 법칙)에서 자연스럽게 따라 나온다.

🔵 [CS 연결] 경사하강법:
  θ_{t+1} = θ_t - α · ∇L(θ_t)
  
  "손실이 가장 빠르게 줄어드는 방향으로 파라미터를 조금 이동"
  이것이 경사하강법의 전부이며, 그래디언트가 핵심이다.
```

### 6.4 헤시안 — 2차 정보

```
🟢 [유도 가능] 1변수에서 f''이 곡률을 알려주듯, 다변수에서는 헤시안이 한다.

  H(f) = [∂²f/∂x_i∂x_j] 행렬   (i,j번째 원소가 2차 편미분)

  2변수 예시:
  H = ┌ ∂²f/∂x²      ∂²f/∂x∂y ┐
      └ ∂²f/∂y∂x     ∂²f/∂y²  ┘

왜 행렬인가:
  1변수: 2차 도함수는 스칼라 하나 → 부호만 보면 됨
  n변수: 각 방향 쌍에 대한 2차 변화율이 있으므로 n×n 행렬이 됨

판정:
  헤시안의 고유값이 모두 양수 → 모든 방향으로 ∪ 모양 → 극소
  헤시안의 고유값이 모두 음수 → 모든 방향으로 ∩ 모양 → 극대
  양수와 음수 혼재 → 안장점 (어떤 방향은 ∪, 어떤 방향은 ∩)

  안장점 시각화:
           ╱╲
         ╱    ╲
  ─────●─────    ← x방향으로는 극소(∪), y방향으로는 극대(∩)
         ╲    ╱       말 안장 모양
           ╲╱

🔵 [CS 연결]
  고차원 신경망에서 안장점이 극소점보다 훨씬 많다.
  차원이 높을수록 모든 고유값이 같은 부호일 확률이 기하급수적으로 낮아지기 때문.
  → SGD가 안장점을 탈출할 수 있는 것은 노이즈 덕분이다.
```

### 6.5 라그랑주 승수법 — 제약이 있는 최적화

```
문제: f(x,y)를 최대/최소화하되, g(x,y) = 0인 조건 하에서

🟢 [유도 가능] 왜 ∇f = λ∇g인가:

  제약 곡선 g(x,y) = 0 위에서만 이동할 수 있다.
  f를 더 좋게 만들려면 ∇f 방향으로 가야 하지만,
  제약 곡선 위에서만 움직여야 한다.
  
  최적점에서는:
  "f를 개선하려면 제약을 벗어나야만 한다"
  → ∇f가 제약 곡선에 수직이다
  → ∇g도 제약 곡선에 수직이다 (g=0의 등고선이므로)
  → ∇f와 ∇g가 평행하다
  → ∇f = λ∇g

  시각화:
                        f의 등고선들
        ── f=1 ── f=2 ── f=3 ──
                     │
              g=0 ───●── g=0     ← 접하는 점에서 ∇f ∥ ∇g
                     │               이것이 최적점

🔵 [CS 연결]
  SVM: 마진을 최대화하되, 분류 제약 조건 하에서 → 라그랑주 승수
  정보이론: 제약 하 최대 엔트로피 분포 유도
```

## 7. 벡터 미적분 — 장(Field)의 미적분

### 7.1 핵심 아이디어

```
스칼라장: 공간의 각 점에 수 하나를 대응 (예: 온도 분포)
벡터장: 공간의 각 점에 벡터를 대응 (예: 바람의 속도)

벡터 미적분은 이런 "장"에 대한 미적분이다.
```

### 7.2 세 가지 핵심 연산자 — 왜 이 세 가지인가

```
🔴 [정의]

  그래디언트 (∇f):  스칼라장 → 벡터장
    "각 점에서 가장 빠르게 증가하는 방향과 그 크기"

  발산 (∇·F):  벡터장 → 스칼라장
    "각 점에서 벡터가 퍼져나가는 정도"
    양수: 원천(source), 음수: 흡수(sink)

  회전 (∇×F):  벡터장 → 벡터장  (3차원)
    "각 점에서 벡터장이 회전하는 정도와 축"

왜 이 세 가지가 근본적인가:
  벡터장의 행동을 완전히 기술하려면 이 세 가지 정보가 필요하다.
  헬름홀츠 분해 정리: 모든 벡터장은 "발산 성분 + 회전 성분"으로 분해된다.
```

### 7.3 그린/스토크스/발산 정리 — 왜 성립하는가

```
이 세 정리는 모두 같은 원리의 변형이다:
  "경계에서의 적분 = 내부에서의 적분"

🟢 발산 정리의 직관:
  상자 안에서 물이 솟아나는 양(발산의 적분)
  = 상자 표면을 통해 빠져나가는 양(표면 플럭스)
  
  왜? 안에서 생성된 것은 결국 경계를 통해 나가야 하니까.
  내부의 한 지점에서 나온 물이 옆 지점으로 가면, 거기서 들어오는 것과
  상쇄된다. 상쇄되지 않는 것은 경계에서만 남는다.

  ∭_V (∇·F) dV = ∯_S F · dS

🔵 [CS 연결]
  유체 시뮬레이션: 나비에-스토크스 방정식이 이 정리들을 사용
  전자기 시뮬레이션: 맥스웰 방정식이 이 정리들로 표현됨
  메쉬 기반 물리 엔진에서 수치적으로 이 적분을 근사
```

## 8. CS에서의 미적분 활용 — 원리가 어떻게 조합되는가

### 8.1 역전파 (Backpropagation) = 연쇄법칙 + 편미분

```
원리의 조합:
  1. 편미분 (§6.2): 각 가중치에 대한 손실의 변화율
  2. 연쇄 법칙 (§3.3): 층을 관통하는 그래디언트 전파
  3. 경사하강법 (§6.3): 그래디언트 반대 방향으로 이동

이 세 가지가 조합되어 "신경망의 학습"이라는 하나의 프로세스가 된다.
역전파는 새로운 수학이 아니라, 미적분 원리들의 효율적 조합이다.
```

### 8.2 푸리에 변환 = 적분 + 삼각함수 + 복소 지수

```
핵심 아이디어:
  "모든 주기 함수는 sin과 cos의 합으로 분해된다"
  
  이것이 성립하는 이유:
  sin과 cos는 직교 함수계(orthogonal system)를 이룬다.
  마치 벡터를 x,y,z 성분으로 분해하듯,
  함수를 sin, cos 성분으로 분해하는 것이다.
  
  (→ Ch.02 선형대수의 "직교 기저"와 같은 원리)

  F(ω) = ∫[-∞,∞] f(t) · e^{-iωt} dt

  e^{-iωt} = cos(ωt) - i·sin(ωt)  (오일러 공식)
  
  → 적분 = f(t)를 sin/cos에 "투영"하는 것 (내적)
  → 선형대수의 내적과 미적분의 적분이 결합된 것

🔵 [CS 연결]
  FFT: O(n²) → O(n log n)으로 가속 (분할 정복)
  JPEG: 이산 코사인 변환(DCT)으로 이미지 압축
  MP3: 주파수 영역에서 사람이 못 듣는 성분 제거
  다항식 곱셈: O(n²) → O(n log n) (FFT 활용)
```

### 8.3 몬테카를로 적분 = 적분 + 확률

```
고차원 적분을 직접 계산하는 것은 비현실적이다.
(10차원에서 각 축을 100등분하면 100^10 = 10^20개의 점을 평가해야 함)

아이디어: "랜덤 샘플링으로 적분을 근사하자"

  ∫_D f(x) dx ≈ (Volume(D) / N) · Σ_{i=1}^{N} f(x_i)
  
  x_i는 D에서 균일 랜덤 샘플

왜 작동하는가:
  큰 수의 법칙 (Ch.03): 샘플 평균은 참 평균에 수렴한다.
  N이 충분히 크면 근사가 정확해진다.
  
  수렴 속도: O(1/√N) — 차원에 무관하다!
  → 고차원에서 유리한 이유

🔵 [CS 연결]
  컴퓨터 그래픽: 렌더링 방정식의 적분 (광선 추적)
  베이즈 추론: 사후 분포의 기댓값 계산 (MCMC)
  강화 학습: 정책의 기대 보상 추정
```

## 10. 정리 — 미적분 전체를 관통하는 원리

```
미적분의 전체 구조는 놀라울 정도로 단순한 원리들의 조합이다:

[원리 1] 극한: "한없이 가까이"를 수학적으로 정의
  ↓ 이것을 변화율에 적용하면
[원리 2] 미분: 순간 변화율 = 접선의 기울기
  ↓ 이것을 반대로 하면
[원리 3] 적분: 변화율의 누적 = 넓이
  ↓ 이 둘의 관계가
[원리 4] 기본정리: 미분과 적분은 역연산

그리고:
[원리 5] 연쇄 법칙: 합성 함수의 미분 → 변화율은 체인처럼 곱해진다
[원리 6] 편미분: 한 변수씩 고정하고 미분 → 다변수 함수를 다루는 전략
[원리 7] 그래디언트: 편미분을 벡터로 모음 → 최대 증가 방향

이 7가지 원리를 이해하면:
  - 곱의 법칙, 몫의 법칙은 정의에서 유도됨
  - 적분 기법들은 미분 법칙의 역과정
  - 경사하강법은 그래디언트의 직접 응용
  - 역전파는 연쇄 법칙 + 편미분의 조합
  - 테일러 급수는 "도함수 일치 조건"에서 유도됨

외워야 할 것:
  🔴 e, sin, cos, ln의 도함수 (자연현상/함수 고유 성질)
  🔴 e의 값과 의미 (자연상수)
  🔴 lim(x→0) sin(x)/x = 1 (원의 기하학)
  🔴 p-판정법 (p > 1 수렴, p ≤ 1 발산)

나머지는 원리를 조합하면 유도할 수 있다.
```
