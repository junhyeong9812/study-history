## 1. 출발점: 데이터 마이닝이란

```
🔴 데이터 마이닝 = "대량의 데이터에서 유용한 패턴을 자동으로 발견하는 과정"

  통계학: 가설을 세우고 검증 (가설 → 데이터)
  데이터 마이닝: 데이터에서 패턴을 발견 (데이터 → 가설)
  머신러닝: 데이터에서 모델을 학습 (데이터 → 모델)
  
  세 분야는 겹치지만 관점이 다르다.
  데이터 마이닝은 "발견"에, 머신러닝은 "예측"에, 통계학은 "추론"에 중점.
```

## 2. 분류 — "이것은 어떤 종류인가"

### 2.1 핵심 알고리즘들 — 각각의 존재 이유

```
🔴 결정 트리 (Decision Tree):
  특성 값으로 데이터를 반복 분할하여 트리 구조를 만든다.
  분할 기준: 정보 이득(Information Gain) = 분할 전후 엔트로피 차이 (Ch.08!)
  
  왜 결정 트리가 인기 있는가:
    해석 가능! "나이 > 30이고 소득 > 5000이면 승인" → 사람이 읽을 수 있다.
    비선형 결정 경계를 만들 수 있다.
  
  문제: 과적합에 취약. 작은 변화에 트리 구조가 크게 바뀜.
  → 해결: 앙상블 (Random Forest, Gradient Boosting)

🔴 k-NN (k-Nearest Neighbors):
  새 데이터의 k개 가장 가까운 이웃의 다수결로 분류.
  
  왜 이것이 작동하는가:
    "비슷한 것은 비슷한 종류일 것이다" — 가장 단순하고 직관적인 가정.
  
  장점: 학습이 필요 없다 (게으른 학습). 구현 간단.
  단점: 예측이 느림 O(n). 차원이 높으면 "차원의 저주"로 성능 급락.

🔴 SVM (Support Vector Machine):
  두 클래스 사이의 "마진(여백)이 최대인 경계선"을 찾는다.
  
  왜 마진 최대화인가:
    마진이 클수록 → 새 데이터가 경계 근처에 있어도 올바르게 분류될 가능성 ↑
    → 일반화 성능이 좋다 (통계적 학습 이론으로 증명 가능).
  
  커널 트릭: 비선형 데이터를 고차원으로 매핑하여 선형 분리 가능하게.
    → Ch.02 선형대수의 내적을 커널 함수로 대체.

🔴 로지스틱 회귀:
  선형 함수 + 시그모이드 → 확률 출력.
  P(y=1|x) = σ(wᵀx + b) = 1/(1+e^{-(wᵀx+b)})
  
  왜 시그모이드인가:
    출력을 0~1로 제한 → 확률로 해석 가능.
    로그 오즈(log-odds)가 입력의 선형 함수라는 가정에서 자연스럽게 유도.
    학습 = 크로스 엔트로피 최소화 = MLE (Ch.03, Ch.08 연결!)
```

## 3. 클러스터링 — "비슷한 것끼리 묶기" (라벨 없음)

```
🔴 K-Means:
  k개의 중심점(centroid)을 반복적으로 업데이트.
  (1) 각 데이터를 가장 가까운 중심에 할당
  (2) 각 클러스터의 평균으로 중심 재계산
  (3) 수렴할 때까지 반복

  왜 수렴하는가:
    각 단계가 "클러스터 내 분산(=비용)"을 감소시키므로.
    비용은 하한이 있고 매 단계 감소 → 반드시 수렴.
    단, 전역 최적은 보장 안 됨 (지역 최적에 빠질 수 있음 → 여러 번 실행).
  
  k를 어떻게 결정하는가:
    Elbow method: k를 늘리면서 비용 그래프의 "꺾이는 점" 관찰.
    Silhouette score: 클러스터 내 밀집도 vs 클러스터 간 분리도.

🔴 DBSCAN (Density-Based):
  밀도가 높은 영역을 클러스터로 인식.
  
  왜 K-Means가 아닌 이것인가:
    K-Means: 구형 클러스터만 잘 찾음. k를 미리 알아야 함.
    DBSCAN: 임의 형태의 클러스터 발견 가능. 노이즈(이상치) 자동 식별. k 불필요.

🔴 계층적 클러스터링 (Hierarchical):
  데이터를 트리(덴드로그램) 형태로 계층 구조화.
  병합(Agglomerative): 개별 → 합치기 반복
  분할(Divisive): 전체 → 쪼개기 반복
  → 덴드로그램을 원하는 높이에서 "잘라서" 클러스터 수 결정.
```

## 4. 연관 규칙 — "함께 사는 것들"

```
🔴 "맥주를 사는 사람은 기저귀도 산다" — 장바구니 분석의 고전

  지지도 (Support): 전체 거래 중 A와 B가 함께 나온 비율
  신뢰도 (Confidence): A를 산 거래 중 B도 산 비율 = P(B|A)
  향상도 (Lift): 신뢰도 / P(B) — 1보다 크면 양의 연관

  Apriori 알고리즘:
    "빈번한 항목 집합의 부분집합도 빈번하다" (Apriori 원리, 하향 폐쇄)
    → 드문 항목 집합을 조기에 가지치기 → 탐색 공간 축소.
    
    왜 이 원리가 성립: {맥주, 기저귀}가 자주 나오려면 {맥주}도 자주 나와야.
    {맥주}가 드물면 {맥주, 기저귀}는 더 드물다 → 볼 필요 없다!

🔵 추천 시스템: "이 상품을 산 고객이 함께 구매한 상품"
   웹 사용 패턴: "이 페이지를 본 사용자가 다음으로 방문한 페이지"
```

## 5. 차원 축소 — "핵심만 남기기"

```
🔴 왜 차원 축소가 필요한가:
  차원의 저주 (Curse of Dimensionality):
    차원이 높을수록 → 데이터가 희소해짐 → 거리가 의미를 잃음
    → k-NN, 클러스터링 등의 성능이 급락.
  
  해결: 중요한 차원만 남기고 나머지를 버린다.

🔴 PCA (Ch.02에서 상세):
  데이터의 분산이 가장 큰 방향(주성분)을 찾아 투영.
  → 선형 차원 축소. 전역 구조 보존.

🔴 t-SNE (t-Distributed Stochastic Neighbor Embedding):
  고차원에서의 "이웃 관계"를 저차원에서 보존.
  → 비선형. 지역 구조 보존에 강함. 시각화에 최적.
  
  왜 PCA가 아닌 t-SNE인가:
    PCA: 전역적 선형 구조 → 복잡한 다양체(manifold) 구조를 놓침
    t-SNE: 지역적 비선형 구조 → 클러스터를 시각적으로 분리

🔴 UMAP: t-SNE보다 빠르고, 전역 구조도 어느 정도 보존. 현재 표준.
```

## 6. 이상 탐지 — "정상이 아닌 것 찾기"

```
🔴 이상(anomaly): 대부분의 데이터와 크게 다른 패턴.

방법들:
  통계 기반: 정규분포 가정 → 평균에서 3σ 이상이면 이상치
  거리 기반: k-NN 거리가 크면 이상치
  밀도 기반: 주변 밀도가 낮으면 이상치 (LOF)
  모델 기반: 오토인코더 복원 오차가 크면 이상치

🔵 사기 탐지(신용카드), 네트워크 침입 탐지, 제조 불량 검출, 의료 이상 진단
```

## 7. 앙상블 — "여럿이 힘을 합치면"

```
🔴 [핵심 원리] 약한 모델 여러 개를 결합하면 강한 모델이 된다.

왜 이것이 작동하는가:
  각 모델이 다른 오류를 범하면 → 다수결로 오류를 상쇄!
  "대중의 지혜" — 개인보다 집단이 평균적으로 더 정확.

🔴 Bagging (Bootstrap Aggregating):
  데이터를 랜덤 복원 추출(bootstrap) → 여러 모델 학습 → 다수결/평균.
  대표: Random Forest = Bagging + 랜덤 특성 선택 + 결정 트리.
  효과: 분산(variance) 감소 → 과적합 방지.

🔴 Boosting:
  이전 모델이 틀린 데이터에 가중치를 높여 다음 모델을 학습.
  대표: AdaBoost, Gradient Boosting (XGBoost, LightGBM, CatBoost).
  효과: 편향(bias) 감소 → 더 정확한 모델.

  왜 Bagging과 Boosting이 다른 문제를 해결하는가:
    Bagging: 독립적 모델 → 분산 감소 (불안정한 모델에 효과적)
    Boosting: 순차적 보완 → 편향 감소 (약한 모델을 강하게)

🔴 Stacking: 여러 모델의 출력을 다시 모델의 입력으로 → "메타 학습"

🔵 Kaggle 대회 상위권 대부분이 앙상블 (특히 Gradient Boosting).
```

## 8. 모델 평가 — "이 모델이 정말 좋은가"

### 8.1 편향-분산 트레이드오프 — 가장 중요한 개념

```
🔴 [원리]
  총 오류 = 편향² + 분산 + 노이즈

  편향 (Bias): 모델이 "너무 단순"해서 패턴을 못 잡음 → 과소적합
  분산 (Variance): 모델이 "너무 복잡"해서 노이즈까지 학습 → 과적합

  모델 복잡도 ↑ → 편향 ↓, 분산 ↑
  모델 복잡도 ↓ → 편향 ↑, 분산 ↓

  오류
    │╲         ╱     ← 분산
    │  ╲     ╱
    │    ╲ ╱         ← 총 오류 (U자형)
    │    ╱ ╲
    │  ╱     ╲       ← 편향
    │╱         ╲
    ┼──────────────── 모델 복잡도
    과소적합    최적    과적합

  🔵 정규화(L1, L2), Dropout, 조기 종료 → 분산을 줄여 최적점을 찾는 도구.
     → Ch.03: L2 정규화 = MAP (정규분포 사전)
```

### 8.2 평가 지표

```
🔴 혼동 행렬 (Confusion Matrix):

                  예측 양성    예측 음성
  실제 양성       TP           FN
  실제 음성       FP           TN

  Accuracy  = (TP+TN) / 전체
  Precision = TP / (TP+FP)   "양성이라고 한 것 중 진짜 양성 비율"
  Recall    = TP / (TP+FN)   "진짜 양성 중 양성이라고 찾은 비율"
  F1        = 2 · (P·R)/(P+R) "정밀도와 재현율의 조화 평균"

  왜 Accuracy만으로 부족한가:
    불균형 데이터: 99%가 음성이면, 무조건 "음성"이라 해도 99% 정확도!
    → Precision, Recall, F1이 필수.

  Precision vs Recall 트레이드오프:
    스팸 필터: Precision 중시 (정상 메일을 스팸으로 분류하면 안 됨)
    암 진단: Recall 중시 (암 환자를 놓치면 안 됨)

🔴 교차 검증 (k-Fold Cross-Validation):
  데이터를 k등분 → k번 반복: 1개를 테스트, 나머지를 학습 → 평균 성능.
  왜: 단일 분할은 운에 따라 결과가 달라짐. k번 평균이면 안정적.
```
