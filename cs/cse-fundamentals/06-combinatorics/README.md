## 1. 출발점: 왜 "세는 것"이 수학인가

### 1.1 조합론이란

```
조합론 = "유한한 구조를 세고, 배열하고, 분석하는 수학"

왜 CS에서 중요한가:

  알고리즘 복잡도 = "이 알고리즘이 몇 번 연산하는가" → 세는 문제
  확률 계산 = "전체 경우의 수 중 원하는 경우의 수" → 세는 문제
  보안 분석 = "비밀번호의 경우의 수는 몇 가지인가" → 세는 문제
  
  세는 것이 정확해야 알고리즘이 효율적이고,
  확률이 정확해야 머신러닝이 작동하고,
  경우의 수가 충분히 커야 보안이 유지된다.
```

## 2. 기본 셈 원리 — 모든 것의 토대

### 2.1 곱의 법칙과 합의 법칙 (Ch.04에서 다뤘으나 심화)

```
🔴 [원리] 
  곱의 법칙: 연속된 독립 선택 → 곱
  합의 법칙: 배타적 대안 → 합

이 두 원리가 모든 조합론의 기반이다.
순열, 조합, 포함-배제 전부가 이 두 가지를 정교하게 적용한 것이다.
```

### 2.2 전단사 원리 — 세기 어려운 것을 세기 쉬운 것으로

```
🔴 [원리] 전단사 원리 (Bijection Principle):
  두 집합 A, B 사이에 전단사 함수가 존재하면 |A| = |B|.

왜 이것이 강력한가:
  직접 세기 어려운 집합 A를 세려면,
  세기 쉬운 집합 B를 찾아 전단사를 만들면 된다.

예시: n비트 이진 문자열의 수 = {0,1}ⁿ의 크기 = 2ⁿ
  ↕ 전단사
  n개 원소 집합의 부분집합의 수 = |P(A)| = 2ⁿ
  
  (각 원소를 "포함(1)/불포함(0)"으로 대응 → 비트 문자열과 전단사)
  
  → 부분집합의 수를 세는 문제가 비트 문자열의 수를 세는 문제로 변환됨

🔵 [CS 연결]
  비트마스크: 부분집합 ↔ 정수 (전단사)
  → 부분집합 열거를 정수 순회로 구현 가능
  for i in range(2**n): → 모든 부분집합 순회
```

### 2.3 이중 계산 (Double Counting)

```
🔴 [원리] 같은 것을 두 가지 방법으로 세면, 두 결과는 같다.

이것이 원리인 이유:
  세는 대상은 하나인데 방법이 다를 뿐.
  따라서 두 방법의 결과를 등치하면 새로운 등식을 얻는다.

예시: 악수 정리
  방법 1: 각 간선은 정확히 2개의 정점에 기여 → 차수 합 = 2|E|
  방법 2: 각 정점의 차수를 직접 합산 → Σ deg(v)
  
  결론: Σ deg(v) = 2|E|  🟢 (Ch.04에서 다룬 것)
```

## 3. 순열과 조합 심화

### 3.1 순열 — 배열의 수학

```
🔴 [정의] P(n, k) = n! / (n-k)!

왜 이 형태인가:
  n개에서 k개를 순서대로 뽑는다:
  첫 번째: n가지 선택
  두 번째: n-1가지 (하나 사용됨)
  ...
  k번째: n-k+1가지
  
  곱의 법칙: n · (n-1) · ... · (n-k+1) = n! / (n-k)!
```

**특수한 순열들:**

```
원순열 (circular permutation):
  원형으로 배열하는 경우의 수 = (n-1)!
  
  왜 n!이 아니라 (n-1)!인가:
  원형에서는 회전해도 같은 배열이다.
  n명을 원형으로 앉힐 때, 한 명을 고정하고 나머지 (n-1)명을 배열.
  → 회전 동치를 제거하면 n!/n = (n-1)!

중복 순열 (permutation with repetition):
  n개에서 중복 허용하여 k개를 뽑아 배열: nᵏ
  
  왜: 각 위치에서 n가지 선택을 독립적으로 한다 (곱의 법칙).
  
  🔵 비밀번호: 62개 문자(대소영+숫자), 8자리 = 62⁸ ≈ 2.18 × 10¹⁴

같은 것이 있는 순열 (multiset permutation):
  n개 중 같은 것이 n₁, n₂, ..., nₖ개씩 있을 때:
  n! / (n₁! · n₂! · ... · nₖ!)
  
  왜: 전체 n!에서 같은 것끼리의 순서 교환(구별 불가)을 나누어 제거.
  
  예시: "MISSISSIPPI"의 배열 수
  11글자: M(1), I(4), S(4), P(2)
  = 11! / (1! · 4! · 4! · 2!) = 34,650
```

### 3.2 조합 심화

```
🟢 [유도 가능] C(n, k)의 성질들 — 정의에서 따라 나온다:

  대칭성: C(n, k) = C(n, n-k)
    왜: k개를 고르는 것 = 안 고를 n-k개를 고르는 것

  파스칼 항등식: C(n, k) = C(n-1, k-1) + C(n-1, k)
    왜: 특정 원소 x를 기준으로
        x를 포함하는 경우: 나머지 n-1개에서 k-1개 선택 = C(n-1, k-1)
        x를 불포함하는 경우: 나머지 n-1개에서 k개 선택 = C(n-1, k)
        합의 법칙으로 더한다.
    
    이것이 파스칼 삼각형의 원리:
    각 수 = 바로 위의 두 수의 합

            1
           1 1
          1 2 1
         1 3 3 1
        1 4 6 4 1
       1 5 10 10 5 1

  반데르몬드 항등식: C(m+n, k) = Σⱼ C(m, j)·C(n, k-j)
    왜: m+n개에서 k개를 뽑을 때, 
        m개 그룹에서 j개, n개 그룹에서 k-j개를 뽑는 모든 방법을 합산.
```

## 4. 이항 정리 — 왜 C(n,k)가 "이항 계수"인가

```
🟢 [유도 가능]
  (x + y)ⁿ = Σ_{k=0}^{n} C(n, k) · xⁿ⁻ᵏ · yᵏ

C(n, k)를 "이항 계수(binomial coefficient)"라 부르는 이유:
  이항식(binomial) (x+y)를 n번 곱할 때, xⁿ⁻ᵏyᵏ 항이 나오는 횟수가 C(n,k)이기 때문.

왜 이것이 성립하는가:
  (x+y)ⁿ = (x+y)(x+y)...(x+y)  [n번]
  
  전개할 때, 각 괄호에서 x 또는 y를 하나씩 선택한다.
  xⁿ⁻ᵏyᵏ이 되려면 n개 괄호 중 k개에서 y를 선택해야 한다.
  k개를 고르는 방법 = C(n, k)가지
  
  → C(n, k)가 계수가 된다.

유용한 특수한 경우들:
  x=1, y=1: Σ C(n,k) = 2ⁿ            (부분집합의 총 수)
  x=1, y=-1: Σ (-1)ᵏ C(n,k) = 0       (짝수 크기 부분집합 = 홀수 크기)

🔵 [CS 연결]
  확률론에서: 이항분포 P(X=k) = C(n,k)pᵏ(1-p)ⁿ⁻ᵏ
  → 이항 정리에서 x=p, y=1-p로 놓은 것: (p+(1-p))ⁿ = 1 = Σ P(X=k) ✓
```

## 5. 포함-배제 원리 — "빼고 더하고"의 체계

### 5.1 왜 포함-배제가 필요한가

```
두 집합이 겹칠 때:
  |A ∪ B| = |A| + |B| - |A ∩ B|

왜 빼야 하는가: A∩B의 원소가 |A|에도, |B|에도 포함되어 두 번 세어지므로.

세 집합:
  |A ∪ B ∪ C| = |A| + |B| + |C|
                - |A∩B| - |A∩C| - |B∩C|
                + |A∩B∩C|

왜 마지막에 다시 더하는가:
  A∩B∩C의 원소는 처음에 3번 더해지고, 빼기에서 3번 빼져서, 0이 된다.
  1번은 세어야 하므로 다시 1번 더한다: 3 - 3 + 1 = 1. ✓
```

### 5.2 일반적 포함-배제

```
🟢 [유도 가능]
  |A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| - ...
                          + (-1)ⁿ⁺¹|A₁∩A₂∩...∩Aₙ|

왜 부호가 교대하는가:
  각 원소가 정확히 1번만 세어지도록 보정하는 과정.
  원소가 m개 집합에 속한다면:
  C(m,1) - C(m,2) + C(m,3) - ... = 1  (이항정리에서 유도)
  
  → 교대로 빼고 더하면 결국 각 원소가 정확히 1번 세어진다.
```

### 5.3 교란 (Derangement) — 포함-배제의 대표적 응용

```
🟢 [유도 가능]
  교란(derangement): 어떤 원소도 원래 위치에 있지 않은 순열
  Dₙ = 아무도 자기 자리에 안 앉는 경우의 수

  Dₙ = n! · Σ_{k=0}^{n} (-1)ᵏ / k!  ≈  n! / e

유도 (포함-배제):
  Aᵢ = "i번째 원소가 제자리에 있는 순열의 집합"
  |Aᵢ| = (n-1)!  (i를 고정하고 나머지 배열)
  |Aᵢ ∩ Aⱼ| = (n-2)!  (i, j 고정)
  |A₁ ∩ ... ∩ Aₖ| = (n-k)!  (k개 고정)
  
  "제자리에 있는 것이 없는" 경우 = 전체 - (하나라도 제자리인 경우)
  Dₙ = n! - |A₁ ∪ ... ∪ Aₙ|
     = n! - [C(n,1)(n-1)! - C(n,2)(n-2)! + ...]
     = n! · [1 - 1/1! + 1/2! - 1/3! + ... + (-1)ⁿ/n!]
     = n! · Σ(-1)ᵏ/k!

  e⁻¹ = Σ(-1)ᵏ/k! (테일러 급수, Ch.01)이므로:
  Dₙ ≈ n!/e

🔵 [CS 연결]
  랜덤 셔플이 완전한 교란일 확률 ≈ 1/e ≈ 36.8%
  시크릿 산타: 아무도 자기 이름을 안 뽑을 확률
  해시 함수 분석: 어떤 키도 원래 버킷에 안 가는 경우
```

## 6. 점화식과 풀이법

### 6.1 점화식이란 — 왜 조합론에서 핵심인가

```
많은 조합론 문제의 답은 점화식(recurrence)으로 표현된다.
"크기 n의 문제 = 더 작은 문제들의 조합"

🔵 이것이 동적 프로그래밍(DP)의 수학적 기반이다 (Ch.10).
```

### 6.2 선형 점화식 풀이 — 특성방정식

```
🟢 [유도 가능]

상수 계수 선형 점화식: aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ...

풀이: 특성방정식 xᵏ = c₁xᵏ⁻¹ + c₂xᵏ⁻² + ...의 근을 구한다.

왜 이것이 작동하는가:
  aₙ = rⁿ 형태의 해를 시도(ansatz)한다.
  rⁿ = c₁rⁿ⁻¹ + c₂rⁿ⁻² 에 대입하면:
  rⁿ⁻² (r² - c₁r - c₂) = 0
  → r² - c₁r - c₂ = 0 (특성방정식)
  
  이 방정식의 근 r₁, r₂가 해의 기본 형태를 결정한다:
  - 서로 다른 근: aₙ = A·r₁ⁿ + B·r₂ⁿ
  - 중근: aₙ = (A + Bn)·rⁿ
  A, B는 초기 조건으로 결정.

예시: 피보나치 수열
  Fₙ = Fₙ₋₁ + Fₙ₋₂,  F₀ = 0, F₁ = 1
  
  특성방정식: r² = r + 1 → r² - r - 1 = 0
  근: r = (1 ± √5) / 2 → φ = (1+√5)/2 ≈ 1.618, ψ = (1-√5)/2 ≈ -0.618
  
  일반해: Fₙ = A·φⁿ + B·ψⁿ
  초기 조건: F₀ = 0 → A + B = 0, F₁ = 1 → Aφ + Bψ = 1
  → A = 1/√5, B = -1/√5
  
  Fₙ = (φⁿ - ψⁿ) / √5
  
  |ψ| < 1이므로 ψⁿ → 0, 따라서 Fₙ ≈ φⁿ/√5
  → 피보나치 수는 지수적으로 성장한다! 성장률 = φ ≈ 1.618 (황금비)
```

## 7. 생성함수 — 수열을 함수로 변환하기

### 7.1 생성함수란 — 왜 이런 도구가 필요한가

```
🔴 [정의] 수열 a₀, a₁, a₂, ...의 (보통) 생성함수:
  G(x) = Σ_{n=0}^{∞} aₙ · xⁿ = a₀ + a₁x + a₂x² + a₃x³ + ...

왜 이렇게 하는가:
  수열을 하나의 함수로 "포장"하면:
  - 수열의 연산(합, 곱, 이동)이 함수의 연산(덧셈, 곱셈, 미분)으로 변환
  - 점화식이 대수 방정식으로 변환
  - 닫힌 형태를 구하기 쉬워짐

  비유: 라플라스/Z 변환처럼, 어려운 영역의 문제를 쉬운 영역에서 풀고 돌아온다.
```

**기본 생성함수들:**

```
🔴 [외워두면 유용]

  1/(1-x) = 1 + x + x² + x³ + ...         수열: (1, 1, 1, ...)
  1/(1-x)² = 1 + 2x + 3x² + 4x³ + ...     수열: (1, 2, 3, ...)
  e^x = 1 + x + x²/2! + x³/3! + ...       수열: (1/0!, 1/1!, 1/2!, ...)

왜 1/(1-x)인가:
  기하급수 Σ xⁿ = 1/(1-x) (|x|<1)
  이것은 Ch.01에서 배운 기하급수 공식이다.
  수열 (1,1,1,...)을 생성한다.
```

### 7.2 생성함수로 점화식 풀기

```
🟢 예시: 피보나치를 생성함수로 풀기

  Fₙ = Fₙ₋₁ + Fₙ₋₂, F₀ = 0, F₁ = 1
  
  G(x) = Σ Fₙxⁿ 으로 놓으면:
  
  G(x) = F₀ + F₁x + Σ_{n≥2} (Fₙ₋₁ + Fₙ₋₂)xⁿ
       = x + x·G(x) + x²·G(x)
  
  G(x)(1 - x - x²) = x
  G(x) = x / (1 - x - x²)

  부분분수 분해 → 계수 추출 → Fₙ = (φⁿ - ψⁿ)/√5
  
  생성함수의 힘:
    점화식 → 대수 방정식 → 부분분수 → 닫힌 형태
    전 과정이 기계적이다!
```

## 8. 카탈란 수 — CS에서 가장 자주 만나는 수열

### 8.1 카탈란 수란 — 왜 이것이 어디서나 나타나는가

```
🔴 [정의]
  Cₙ = C(2n, n) / (n+1) = (2n)! / ((n+1)! · n!)

  C₀=1, C₁=1, C₂=2, C₃=5, C₄=14, C₅=42, ...

  점화식: Cₙ = Σ_{i=0}^{n-1} Cᵢ · Cₙ₋₁₋ᵢ,  C₀ = 1

카탈란 수가 세는 것들 — 이것들이 전부 같은 수라는 것이 놀랍다:

  1. n쌍의 올바른 괄호 배열 수
     n=3: ((())), (()()), (())(), ()(()), ()()()  → 5 = C₃

  2. n+1개 잎을 가진 이진 트리의 형태 수

  3. n+2각형의 삼각형 분할 수

  4. n×n 격자에서 대각선 위로 넘지 않는 경로 수

왜 이것들이 같은 수인가:
  모두 "재귀적으로 두 부분으로 나누는 구조"를 가지고 있다.
  
  괄호: 첫 번째 '('와 매칭되는 ')'를 기준으로 왼쪽과 오른쪽으로 분할
  이진 트리: 루트를 기준으로 왼쪽 서브트리와 오른쪽 서브트리로 분할
  
  이 분할 구조가 정확히 같은 점화식 Cₙ = Σ Cᵢ·Cₙ₋₁₋ᵢ를 만든다.
  → 전단사 원리: 구조가 같으면 수도 같다.

🔵 [CS 연결]
  컴파일러: 올바른 괄호 구조 = 파싱 트리의 형태 수
  DB: 조인 순서의 가능한 수 = 카탈란 수
  알고리즘: 행렬 체인 곱셈의 괄호 치는 방법 수 = 카탈란 수
  자료구조: n개 노드의 BST 형태 수 = 카탈란 수
```

## 9. 뫼비우스 반전 — "빼기"의 체계화

```
🔴 [원리] 뫼비우스 반전 (Möbius Inversion):
  약수 관계에서:
  g(n) = Σ_{d|n} f(d)  이면  f(n) = Σ_{d|n} μ(n/d) · g(d)

  μ(n) = 뫼비우스 함수:
    μ(1) = 1
    μ(n) = (-1)ᵏ  (n이 서로 다른 소수 k개의 곱일 때)
    μ(n) = 0      (n이 소수의 제곱을 인수로 가질 때)

왜 이것이 중요한가:
  포함-배제의 정수론 버전이다.
  "쉬운 합(g)"에서 "원하는 값(f)"을 추출하는 도구.

🔵 [CS 연결]
  경쟁 프로그래밍: 약수 합/곱 관련 문제에서 자주 등장
  오일러 파이 함수의 공식 유도:
    φ(n) = n · Π_{p|n} (1 - 1/p) — 뫼비우스 반전으로 증명 가능
```

## 10. 번사이드 보조정리 — 대칭성을 고려한 셈

```
🔴 [정리] 번사이드 보조정리 (Burnside's Lemma):
  대칭군 G의 작용 하에서 구별되는 패턴의 수:
  
  |X/G| = (1/|G|) · Σ_{g∈G} |Fix(g)|

  Fix(g) = g에 의해 변하지 않는 원소(고정점)의 수

왜 필요한가:
  구슬 목걸이를 만들 때, 회전해도 같은 목걸이는 하나로 세야 한다.
  단순히 경우의 수를 세면 회전 동치인 것을 중복 계산하게 된다.
  번사이드 보조정리가 이 중복을 정확히 보정한다.

예시: 3색으로 정사각형의 꼭짓점을 칠하는 구별되는 방법
  총 칠하기: 3⁴ = 81
  대칭군 G: 항등, 90°, 180°, 270° 회전 (|G| = 4)
  
  Fix(항등) = 81 (모두 고정)
  Fix(90°) = 3 (4개 꼭짓점 모두 같은 색)
  Fix(180°) = 9 (대각선 쌍이 같은 색, 3² = 9)
  Fix(270°) = 3
  
  구별되는 패턴 = (81 + 3 + 9 + 3) / 4 = 24

🔵 [CS 연결]
  분자 구조 분석: 회전 동치인 분자 구조 세기
  타일링 문제: 대칭을 고려한 타일 배치 수
  게임 상태 분석: 회전/대칭으로 동일한 보드 상태 제거
```
