## 1. 출발점: 왜 컴퓨터에게 "보는 것"이 어려운가

```
인간: 이미지를 보면 즉시 "고양이가 소파에 앉아 있다"를 안다.
컴퓨터: 이미지 = 숫자(픽셀값)의 2차원 배열. 어디가 고양이인지 모른다!

왜 어려운가:
  (1) 같은 물체도 각도, 조명, 크기, 가림에 따라 픽셀이 완전히 다르다.
  (2) 다른 물체가 비슷한 픽셀 패턴을 가질 수 있다.
  (3) 배경과 물체를 구분해야 한다.
  
  → 픽셀 값 자체가 아니라 "패턴"과 "구조"를 인식해야 한다.
  → 이것이 CNN이 하는 일: 저수준 패턴(엣지) → 중간 수준(질감) → 고수준(물체)
```

## 2. 이미지 표현

```
🔴 디지털 이미지 = 픽셀의 2D 배열

  그레이스케일: H × W 행렬. 각 값 0(검정)~255(흰색).
  컬러 (RGB): H × W × 3 텐서. 각 채널이 R, G, B.

  224 × 224 × 3 이미지 = 150,528개의 숫자!
  → 이것을 직접 입력으로 쓰면 차원이 너무 높다 → 특징 추출이 필수.
```

## 3. 컨볼루션 — CV의 핵심 연산

### 3.1 왜 컨볼루션인가

```
🔴 [핵심 아이디어] 작은 필터(커널)를 이미지 위에 슬라이딩하며 국소적 패턴을 감지.

  입력 이미지:          3×3 필터:         출력:
  ┌───┬───┬───┬───┐    ┌───┬───┬───┐
  │ 1 │ 2 │ 3 │ 0 │    │ 1 │ 0 │-1 │    각 위치에서
  ├───┼───┼───┼───┤    ├───┼───┼───┤    필터와 겹치는
  │ 0 │ 1 │ 2 │ 1 │    │ 1 │ 0 │-1 │    영역의 원소별 곱
  ├───┼───┼───┼───┤    ├───┼───┼───┤    의 합을 계산
  │ 1 │ 0 │ 1 │ 2 │    │ 1 │ 0 │-1 │
  └───┴───┴───┴───┘    └───┴───┴───┘

  왼쪽 위 3×3 영역과 필터의 연산:
  1×1 + 2×0 + 3×(-1) + 0×1 + 1×0 + 2×(-1) + 1×1 + 0×0 + 1×(-1) = -2

왜 이것이 패턴 감지인가:
  위 필터 [1,0,-1; 1,0,-1; 1,0,-1]은 "수직 엣지 검출기"이다.
  왼쪽이 밝고 오른쪽이 어두운 경계에서 큰 값이 나온다.
  
  → 필터의 값이 "무엇을 감지하는가"를 결정.
  → CNN에서는 필터의 값을 학습한다! (사람이 설계하지 않음)

왜 전체 이미지가 아닌 "국소적" 패턴인가:
  (1) 지역성: 물체의 특징은 국소적 (눈, 코, 귀는 작은 영역에 있다)
  (2) 파라미터 공유: 같은 필터를 전체 이미지에 적용 → 파라미터 수 극감
      완전연결(FC): 224×224×3 → 100 뉴런 = 1500만 파라미터!
      컨볼루션: 3×3 필터 = 9개 파라미터로 전체 이미지 처리!
  (3) 이동 불변성: 고양이가 어디에 있든 같은 필터가 감지
```

### 3.2 풀링 — 왜 줄이는가

```
🔴 풀링 (Pooling): 특징 맵의 크기를 줄이는 다운샘플링.

  Max Pooling (2×2, stride 2):
  ┌───┬───┬───┬───┐        ┌───┬───┐
  │ 1 │ 3 │ 2 │ 1 │        │ 3 │ 2 │
  ├───┼───┼───┼───┤   →    ├───┼───┤
  │ 2 │ 1 │ 0 │ 4 │        │ 2 │ 4 │
  ├───┼───┼───┼───┤        └───┴───┘
  │ 1 │ 2 │ 3 │ 1 │
  ├───┼───┼───┼───┤
  │ 0 │ 1 │ 2 │ 0 │

  각 2×2 영역에서 최대값만 취함.

왜 풀링하는가:
  (1) 계산량 감소: 크기가 절반 → 연산 1/4
  (2) 작은 이동에 불변: 패턴이 1~2 픽셀 이동해도 max값은 같음
  (3) 수용장(receptive field) 확대: 더 넓은 영역의 정보를 집약
```

## 4. CNN 아키텍처 — 계층적 특징 학습

### 4.1 왜 층을 깊게 쌓는가

```
🔴 [핵심 원리] 낮은 층 → 단순 패턴, 높은 층 → 복잡한 패턴

  Layer 1: 엣지 (수평, 수직, 대각선)
  Layer 2: 질감, 모서리 (엣지의 조합)
  Layer 3: 부분 (눈, 코, 바퀴)
  Layer 4~5: 물체 전체 (얼굴, 자동차)

  왜 이런 계층이 자연스러운가:
    시각 세계 자체가 계층적이다.
    물체 = 부분들의 조합 = 패턴들의 조합 = 엣지들의 조합
    → CNN이 이 구조를 자연스럽게 학습.
```

### 4.2 대표 아키텍처 — 각각의 혁신

```
🔴 주요 모델들과 각각이 해결한 문제:

  LeNet (1998): 최초의 CNN. 숫자 인식. 컨볼루션+풀링의 원형.
  
  AlexNet (2012): ImageNet에서 압승. GPU 학습, ReLU, Dropout.
    왜 중요: "딥러닝이 작동한다"를 세상에 증명한 모델.
  
  VGGNet (2014): "더 깊게" — 3×3 필터만 반복. 깊이의 힘을 증명.
    왜 3×3만: 5×5 하나 = 3×3 두 개. 같은 수용장, 적은 파라미터, 더 많은 비선형성.
  
  🔴 ResNet (2015): "잔차 연결(skip connection)"
    문제: 너무 깊으면 오히려 성능이 떨어진다! (기울기 소실/폭발)
    해결: y = F(x) + x  (입력을 출력에 직접 더함)
    
    왜 이것이 작동하는가:
      F(x) = 0이면 y = x → 항등 함수! (최소한 성능이 떨어지지 않음)
      네트워크가 "변화량(잔차)"만 학습 → 학습이 쉬워짐.
      그래디언트가 skip connection을 통해 직접 흐름 → 소실 방지!
    
    → 100+ 층이 가능해짐. 현대 CV의 기본 구성 요소.

  EfficientNet (2019): 깊이, 너비, 해상도의 균형 잡힌 스케일링.
```

## 5. 주요 CV 태스크

### 5.1 이미지 분류 → 객체 탐지 → 세그멘테이션

```
🔴 세 가지 태스크의 관계:

  분류 (Classification): "이 이미지에 고양이가 있는가?" → 전체 이미지에 하나의 라벨
  객체 탐지 (Detection): "고양이가 어디에 있는가?" → 바운딩 박스 + 라벨
  세그멘테이션 (Segmentation): "어떤 픽셀이 고양이인가?" → 픽셀별 라벨

  난이도: 분류 < 탐지 < 세그멘테이션

객체 탐지 — YOLO:
  "한 번만 본다(You Only Look Once)" — 이미지를 그리드로 나누고,
  각 그리드 셀에서 동시에 바운딩 박스와 클래스를 예측.
  → 실시간 탐지 가능! (30+ FPS)
  
  왜 빠른가:
    R-CNN 계열: 영역 제안 → 각 영역을 CNN에 통과 → 느림 (수천 번 CNN 실행)
    YOLO: 전체 이미지를 한 번에 CNN → 빠름

세그멘테이션 — U-Net:
  인코더(축소) + 디코더(확대) + 스킵 연결
  인코더에서 추출한 세부 특징을 디코더에 전달 → 정밀한 경계 복원.
  → 의료 영상에서 특히 활약 (세포, 종양 경계).

평가 지표:
  🔴 IoU = (예측 ∩ 정답) / (예측 ∪ 정답)
    0: 완전 불일치, 1: 완전 일치. 보통 0.5 이상이면 "맞음".
  🔴 mAP: 각 클래스의 AP(Average Precision)의 평균.
```

## 6. 이미지 생성 — "없던 이미지를 만들기"

```
🔴 GAN (Generative Adversarial Network, 2014):
  생성자(Generator) vs 판별자(Discriminator)의 경쟁.
  
  G: 랜덤 노이즈 → 가짜 이미지 생성
  D: 진짜/가짜를 판별
  
  G는 D를 속이려 하고, D는 속지 않으려 한다.
  → 경쟁을 통해 G가 점점 사실적인 이미지를 생성!
  
  게임 이론(미니맥스)으로 정식화:
    min_G max_D [E[log D(x)] + E[log(1 - D(G(z)))]]

🔴 Diffusion Models (2020~):
  이미지에 노이즈를 점진적으로 추가(정방향) → 노이즈에서 이미지를 복원(역방향)
  
  정방향: 깨끗한 이미지 → 약간 노이지 → ... → 완전 노이즈
  역방향: 완전 노이즈 → 약간 덜 노이지 → ... → 깨끗한 이미지!
  
  왜 GAN보다 안정적인가:
    GAN: 두 네트워크의 균형 유지가 어려움 (모드 붕괴 등)
    Diffusion: 단일 네트워크가 노이즈 제거만 학습 → 학습이 안정적
    
  대가: 생성 속도가 느림 (수십~수백 단계 반복)
  해결: DDIM, LCM 등으로 단계 수 축소

🔵 DALL-E, Stable Diffusion, Midjourney = Diffusion 기반
```

## 7. Vision Transformer (ViT) — CNN 없이도 가능한가

```
🔴 ViT (2020): 이미지를 패치로 쪼개고 Transformer에 입력.

  이미지 224×224 → 16×16 패치 196개 → 각 패치를 벡터로 → Transformer!

  왜 이것이 작동하는가:
    패치 = "시각적 토큰". NLP의 단어 토큰처럼 처리.
    Self-Attention이 패치 간 관계를 학습.
    → 전역적 관계를 처음부터 포착 (CNN은 점진적으로 수용장 확대)

  CNN vs ViT:
    CNN: 귀납적 편향(locality, 이동 불변성) 내장 → 적은 데이터에서도 잘 작동
    ViT: 편향 없음 → 대규모 데이터에서 CNN을 능가. 적은 데이터에서는 열세.
    
    → 데이터가 충분하면 ViT, 부족하면 CNN (또는 하이브리드)
```

## 8. 전이 학습 — "바퀴를 다시 발명하지 마라"

```
🔴 전이 학습: ImageNet 등에서 사전학습된 모델을 가져와 특정 태스크에 적용.

  왜 이것이 작동하는가:
    낮은 층의 특징(엣지, 질감)은 거의 모든 이미지에 공통!
    높은 층만 새 태스크에 맞게 조정하면 된다.
    
    → 적은 데이터로도 높은 성능 가능!
    → 의료 이미지(데이터 부족)에서 특히 유용.

  방법:
    Feature extraction: 사전학습 모델을 고정, 마지막 분류기만 교체
    Fine-tuning: 사전학습 모델의 일부/전체를 새 데이터로 추가 학습
```
